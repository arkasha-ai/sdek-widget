### Nested Sub-agents (2026-02-20)
**Работает!** Sub-agents могут создавать своих sub-agents (проверено экспериментально).

**Use case:** Массовая обработка репозиториев
- Main → spawn по sub-agent на каждый repo
- Каждый repo sub-agent → spawn по sub-agent на каждый module
- Параллелизм + изоляция

**Ограничения:**
- Tokens budget (каждый уровень ест токены)
- Resource limits (max одновременных sub-agents)
- Debugging сложность (nested failures)

**Статус:** Отложено до реальной задачи, техника подтверждена.
