## 3. ML Pipeline — ядро системы (10 недель)

### 3.1 ASR модуль — VoiceCore™ (3 недели)
- **Интеграция Whisper Large V3 Turbo (1 неделя):**
  - faster-whisper с CTranslate2 для GPU-инференса
  - Streaming mode (chunked audio → partial results)
  - Поддержка 16 kHz / 48 kHz input
  - Оптимизация latency до ~300-400ms

- **SmartPause™ Detection (1 неделя):**
  - VAD (Voice Activity Detection) — Silero VAD
  - Детекция пауз и сегментация речи на фразы
  - Адаптивные пороги (длина паузы, уровень шума)
  - Буферизация для контекстного перевода

- **Адаптация и языки (1 неделя):**
  - Prompt conditioning для адаптации под спикера
  - Приоритетные языки: EN, RU, HI
  - Тестирование точности >95% на каждом языке
  - Обработка акцентов и шумов

- **Команда:** ML-инженер, Backend

### 3.2 NMT модуль — NeuroTranslate™ (3 недели)
- **Интеграция NLLB-200 / SeamlessM4T (1.5 недели):**
  - Развёртывание модели на GPU (FP16/INT8 квантизация)
  - 200+ языковых пар
  - Контекстное окно до 512 токенов
  - Streaming mode с partial results

- **Интеграция с глоссарием (1 неделя):**
  - Constrained decoding — приоритет терминов глоссария
  - Правила "не переводить" (коды, названия препаратов)
  - Фармацевтическая терминология (EN↔RU↔HI)
  - Fallback на общий перевод при отсутствии термина

- **Оптимизация качества (0.5 недели):**
  - Бенчмарки BLEU/COMET на тестовых данных
  - Fine-tuning на доменных данных (фарма, если есть корпус)
  - A/B сравнение NLLB vs SeamlessM4T

- **Команда:** ML-инженер, NLP-специалист (консультант)

### 3.3 TTS модуль — VoiceSynth™ (2 недели)
- **Интеграция нейросетевого TTS (1 неделя):**
  - Coqui TTS / XTTS v2 для нейросинтеза
  - Streaming mode (~600ms latency)
  - Качество 24 kHz, 16 bit
  - 3 приоритетных языка (EN, RU, HI)

- **Голоса и качество (1 неделя):**
  - Подбор голосов для каждого языка (MOS >4.0)
  - Тестирование естественности и интонации
  - Premium голоса (опция — voice cloning через XTTS)
  - Фонетические транскрипции из глоссария → корректное произношение терминов

- **Команда:** ML-инженер, Audio-инженер (консультант)

### 3.4 StreamOrchestrator™ (2 недели)
- **Pipeline оркестрация (1.5 недели):**
  - WebSocket сервер для приёма аудиопотоков
  - Асинхронный pipeline: ASR → NMT → TTS
  - Буферизация и управление очередями
  - Параллельная обработка 2 потоков (STANDARD) / 4 потоков (PREMIUM)
  - End-to-end latency контроль (<2000ms)
  - Graceful degradation при перегрузке

- **WebRTC модуль (0.5 недели):**
  - WebRTC gateway для low-latency аудио
  - Opus кодек (input/output)
  - Jitter buffer, echo cancellation
  
- **Команда:** Backend Senior, ML-инженер
