## 2. Архитектура пайплайна

### Диаграмма потока

```
INPUT: photo_url? + product_data
         │
    ┌────▼────┐
    │ Есть    │
    │ фото?   │
    └──┬──┬───┘
   Да  │  │ Нет
       │  │
  ┌────▼┐ ┌▼────────────┐
  │rm-bg│ │ Генерация   │
  │     │ │ flux-dev     │
  └──┬──┘ └──┬──────────┘
     │       │
     ▼       ▼
  product_on_white.png     ← ПАРАЛЛЕЛЬНО с этого момента
     │
     ├──────────────────────────────────────────────────┐
     │                                                  │
     ▼                     ▼                            ▼
  ┌──────────┐  ┌──────────────────┐  ┌──────────────────────┐
  │ Slide 2  │  │ Slide 3          │  │ Slide 5              │
  │ Info     │  │ Lifestyle        │  │ Sizes/Specs          │
  │ recraft  │  │ flux-kontext-pro │  │ recraft-v4           │
  └──────────┘  └──────────────────┘  └──────────────────────┘
     │                     │                            │
     ▼                     ▼                            ▼
  ┌──────────────────────────────────────────────────────┐
  │              COMPOSE (ImageMagick/Pillow)            │
  │     Наложение текстовых оверлеев, цена, скидка       │
  └──────────────────────────────────────────────────────┘
     │
     ▼
  OUTPUT: 4-8 готовых PNG файлов
```

### Детальные шаги

#### Шаг 0: Подготовка данных
- **Input:** `product_data` (JSON: name, price, old_price, description, features[], category, brand)
- **Output:** Промпты для каждого слайда, параметры оверлеев
- **Инструмент:** LLM (llm-task) — генерация промптов из описания товара
- **Стоимость:** ~$0.002 (Sonnet)
- **Время:** ~2 сек

#### Шаг 1: Базовое изображение товара
- **Ветка A (есть фото):**
  - `lucataco/remove-bg` — удаление фона → PNG с альфа-каналом
  - **Cost:** ~$0.002, **Time:** ~2 сек
- **Ветка B (нет фото):**
  - `flux-dev` — генерация товара из промпта, белый фон
  - **Cost:** $0.025, **Time:** ~10 сек
- **Output:** `product_clean.png`

#### Шаг 2: Главное фото (Slide 1)
- **Input:** `product_clean.png`
- **Action:** Наложение на чисто белый фон 1440×1920, центрирование
- **Инструмент:** Pillow (локально, бесплатно)
- **Cost:** $0, **Time:** <1 сек

#### Шаг 3: Инфо-карточка (Slide 2) — ПАРАЛЛЕЛЬНО
- **Input:** `product_clean.png` + features text
- **Model:** `recraft-v4` — лучший для дизайна с текстом
- **Prompt:** "{product_name} product card infographic, white background, {feature1}, {feature2}, {feature3}, clean modern design, 3:4 vertical"
- **Cost:** $0.040, **Time:** ~10 сек

#### Шаг 4: Lifestyle (Slide 3) — ПАРАЛЛЕЛЬНО
- **Input:** `product_clean.png`
- **Model:** `flux-kontext-pro` — вклеивает товар в сцену
- **Prompt:** "Place this product in a {context_scene}, natural lighting, lifestyle photography"
- **Cost:** $0.040, **Time:** ~8 сек

#### Шаг 5: Размеры/характеристики (Slide 4) — ПАРАЛЛЕЛЬНО
- **Model:** `recraft-v4` — текст + дизайн
- **Prompt:** "{product_name} specification card, dimensions {W}x{H}x{D} cm, weight {W} kg, material: {material}, clean infographic style"
- **Cost:** $0.040, **Time:** ~10 сек

#### Шаг 6: Текстовые оверлеи
- **Input:** Все слайды + product_data (цена, скидка, бейджи)
- **Инструмент:** Pillow / ImageMagick (локально)
- **Action:** Наложение цены, скидки, водяного знака бренда
- **Cost:** $0, **Time:** ~2 сек

### Параллельность

```
Шаг 0 (промпты)                         [2s]
  └→ Шаг 1 (remove-bg ИЛИ генерация)    [2-10s]
      └→ Шаг 2 (главное фото)           [<1s]
      ├→ Шаг 3 (инфо-карточка)          [10s] ─┐
      ├→ Шаг 4 (lifestyle)              [8s]  ─┤ ПАРАЛЛЕЛЬНО
      └→ Шаг 5 (размеры)               [10s] ─┘
          └→ Шаг 6 (оверлеи)            [2s]

Общее время: ~16-24 сек (не сумма, а с параллельностью)
```

## 3. Lobster — вердикт

### Текущее состояние

**Lobster CLI НЕ установлен** на сервере (`which lobster` → пусто). Установка требует отдельного бинарника из [openclaw/lobster](https://github.com/openclaw/lobster).

### Подходит ли Lobster для этой задачи?

**Частично, но НЕ оптимально.** Причины:

1. **Lobster — pipe-based**: `cmd1 | cmd2 | cmd3`. Наш пайплайн — **дерево** (fan-out после remove-bg), а не линейная цепочка. Lobster не умеет нативный параллелизм (fan-out/fan-in).

2. **Состояние между шагами**: Нужно передавать файловые пути и URL между шагами. Lobster передаёт JSON через stdin/stdout, что ограничивает.

3. **Нет нативного await/parallel**: Шаги 3, 4, 5 должны идти параллельно. В Lobster это потребует внешнего оркестратора.

4. **Наш скилл — Python**: generate.py уже написан на Python, весь tooling (Pillow, curl) — Python. Добавлять слой Lobster — лишняя абстракция.

### Рекомендация

**Python pipeline script** — основной рантайм. Lobster — опциональная обёртка для запуска через OpenClaw tool.

#### Если хотим Lobster (workflow file)

```yaml
# product-card.lobster
name: product-card-pipeline
args:
  photo_url:
    default: ""
  product_json:
    required: true
steps:
  - id: generate
    command: >
      python3 ~/.openclaw/workspace/skills/qwen-image-gen/scripts/product_card_pipeline.py
      --product-json '${{ args.product_json }}'
      --photo-url '${{ args.photo_url }}'
      --output-dir ~/.openclaw/workspace/drafts/cards/
    timeout: 120s
  - id: approve
    command: echo "Generated card set"
    stdin: $generate.stdout
    approval: required
```

Вызов через OpenClaw:
```json
{
  "action": "run",
  "pipeline": "~/.openclaw/workspace/skills/qwen-image-gen/product-card.lobster",
  "argsJson": "{\"product_json\": \"{...}\", \"photo_url\": \"https://...\"}",
  "timeoutMs": 180000
}
```

#### Реальный подход: Python script + openclaw.invoke

Запускаем Python скрипт напрямую через `exec`, или вызываем из Lobster как single step. Вся логика параллельности и ветвлений — внутри Python (через `concurrent.futures.ThreadPoolExecutor`).

### Когда это окупается?

- **Продавец с 10+ товарами** — окупается сразу vs любой другой вариант
- **Новый ассортимент (100+ SKU)** — единственный реалистичный вариант по срокам
- **A/B тестирование карточек** — можно сгенерировать 3-5 вариантов каждой карточки за $0.50-1.50 и тестировать конверсию
- **Сезонное обновление** — перегенерация всех карточек с новогодними/летними оверлеями за копейки

### Ограничения

1. **Качество фото товара** — AI не заменит профессиональную съёмку для premium брендов
2. **Уникальные ракурсы** — AI генерирует, но не снимает реальный товар с разных сторон
3. **Точность цветопередачи** — сгенерированные изображения могут отличаться от реального товара
4. **Текст на инфографике** — AI пока не идеален в русском тексте на изображениях (recraft-v4 лучше всех)

### Что можно улучшить позже

- **Шаблоны** — сохранять удачные промпты/стили как пресеты по категориям
- **Пакетная генерация** — CSV/JSON с товарами → массовая обработка
- **A/B варианты** — генерация 2-3 вариантов каждого слайда для выбора
- **Брендинг** — единый стиль через LoRA / style reference
- **Видео** — следующий уровень: AI видео-превью товара (Kling, Runway)
