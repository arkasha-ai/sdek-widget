## 📍 Модуль 1. Промптинг — разговаривай с AI правильно
**⏱ 1-2 недели | Сложность: ⭐☆☆☆☆**

### Что такое промпт и почему это важно
Промпт — это инструкция для нейросети. 80% результата зависит от того, как ты формулируешь задачу.

### Инструменты модуля
| Инструмент | Для чего | Цена |
|------------|----------|------|
| [ChatGPT](https://chat.openai.com) | Универсальный старт | Бесплатно / $20/мес |
| [Claude](https://claude.ai) | Длинные тексты, анализ | Бесплатно / $20/мес |
| [Gemini](https://gemini.google.com) | Работа с файлами и таблицами | Бесплатно |
| [Perplexity](https://perplexity.ai) | Поиск с AI | Бесплатно |

### Ключевые техники
- **Role prompting** — "Ты опытный маркетолог с 10 годами опыта..."
- **Chain-of-Thought** — "Думай пошагово: сначала X, потом Y"
- **Few-shot** — показываешь примеры того что хочешь получить
- **Structured output** — просишь вернуть результат в таблице / JSON / списке
- **Итерация** — дорабатывать через диалог, не переписывать с нуля

### Ресурсы
- 📖 [Prompt Engineering Guide (RU)](https://www.promptingguide.ai/ru) — лучший бесплатный гайд
- 📖 [Learn Prompting](https://learnprompting.org) — интерактивные уроки
- 🎥 YouTube: "Промптинг ChatGPT 2025" — любой свежий ролик

### Практическое задание
1. Напиши промпт который генерирует резюме под конкретную вакансию
2. Сделай промпт который анализирует договор и выделяет риски
3. Создай шаблон промпта для написания холодных писем

## 🎨 Модуль 2. Генерация изображений
**⏱ 1 неделя | Сложность: ⭐⭐☆☆☆**

### Как это работает
Ты описываешь картинку текстом — нейросеть её рисует. Используется для: маркетинга, презентаций, концепт-артов, аватаров, рекламы.

### Инструменты модуля
| Инструмент | Сильная сторона | Цена |
|------------|-----------------|------|
| [Midjourney](https://midjourney.com) | Лучшее художественное качество | $10/мес |
| [DALL-E 3](https://chat.openai.com) | Встроен в ChatGPT, удобно | Входит в ChatGPT Plus |
| [Leonardo.ai](https://leonardo.ai) | Много бесплатных кредитов | Бесплатно / $12/мес |
| [Stable Diffusion](https://stability.ai) | Бесплатно, локально | Бесплатно (нужен GPU) |
| [Adobe Firefly](https://firefly.adobe.com) | Безопасно для коммерции | Бесплатно / от $5/мес |

### Ключевые техники
- **Описание стиля** — "в стиле минимализм, flat design, cinematic"
- **Negative prompts** — что НЕ должно быть на картинке
- **Aspect ratio** — формат изображения (16:9, 1:1, 9:16)
- **Reference image** — давать пример картинки за основу
- **Inpainting** — изменять только часть изображения

### Ресурсы
- 📖 [Civitai.com](https://civitai.com) — тысячи промптов и моделей
- 🎥 YouTube: "Midjourney для начинающих 2025"
- 🎥 YouTube: "Leonardo AI tutorial"

### Практическое задание
1. Сгенерируй 5 вариантов баннера для своего проекта
2. Создай аватар в деловом стиле
3. Сделай иллюстрацию для презентации

## 🎬 Модуль 3. Генерация видео и голоса
**⏱ 1-2 недели | Сложность: ⭐⭐⭐☆☆**

### Возможности
Генерировать видео из текста, оживлять фото, клонировать голос, создавать аватары-ведущих, озвучивать на другом языке.

### Инструменты модуля
| Инструмент | Для чего | Цена |
|------------|----------|------|
| [Runway Gen-3](https://runwayml.com) | Видео из текста и фото, топ качество | $15/мес |
| [Kling AI](https://klingai.com) | Видео из текста, конкурент Runway | Бесплатно / $10/мес |
| [HeyGen](https://heygen.com) | Видео-аватары, дубляж | $29/мес |
| [ElevenLabs](https://elevenlabs.io) | Клонирование голоса, озвучка | Бесплатно / $5/мес |
| [Sora](https://sora.com) | Видео от OpenAI | $20/мес (ChatGPT Plus) |
| [CapCut AI](https://capcut.com) | Монтаж с AI функциями | Бесплатно |

### Ключевые техники
- **Text-to-video** — описание → видеоролик
- **Image-to-video** — фото → анимация
- **Voice cloning** — клонируешь свой голос один раз, используешь всегда
- **Lip sync** — синхронизация речи с движением губ
- **Video translation** — перевод видео с сохранением голоса

### Ресурсы

2. Озвучь текст клонированным голосом через ElevenLabs
3. Сделай видео-аватар который рассказывает о тебе

## ⚙️ Модуль 4. Автоматизация без кода
**⏱ 2-3 недели | Сложность: ⭐⭐⭐☆☆**

### Что такое автоматизация
Ты соединяешь разные сервисы между собой + добавляешь AI — и они работают без тебя. Например: новое письмо → AI анализирует → создаёт задачу в Jira → уведомляет в Telegram.

### Инструменты модуля
| Инструмент | Для чего | Цена |
|------------|----------|------|
| [n8n](https://n8n.io) | Open-source автоматизация, лучший для AI | Бесплатно (self-hosted) / $20/мес |
| [Make](https://make.com) | Визуальные сценарии, проще чем n8n | Бесплатно / $9/мес |
| [Zapier](https://zapier.com) | Много интеграций, простой | $20/мес |
| [Voiceflow](https://voiceflow.com) | AI чат-боты | Бесплатно / $40/мес |

### Что можно автоматизировать
- Обработка входящих писем
- Публикация контента в соцсети
- Мониторинг вакансий (как у тебя сейчас!)
- CRM + AI = автоматические follow-up
- Отчёты из данных

### Ресурсы
- 📖 [n8n Docs](https://docs.n8n.io)
- 🎥 YouTube: "n8n AI automation tutorial 2025"
- 🎥 YouTube: "Make.com for beginners"

### Практическое задание
1. Настрой автоматическую отправку уведомления при новом письме
2. Создай бота который отвечает на вопросы о твоих услугах
3. Сделай сценарий: новая вакансия на hh → анализ AI → уведомление в Telegram

## 🤖 Модуль 5. AI-агенты
**⏱ 1-2 месяца | Сложность: ⭐⭐⭐⭐☆**

### Что такое агент
Агент — это AI который не просто отвечает, а **действует**: ищет информацию, управляет файлами, заходит на сайты, выполняет задачи последовательно. Думает и делает, а не только говорит.

### Инструменты модуля
| Инструмент | Для чего | Сложность |
|------------|----------|-----------|
| [Dify](https://dify.ai) | No-code агенты с UI | ⭐⭐ |
| [CrewAI](https://crewai.com) | Мульти-агентные системы (Python) | ⭐⭐⭐ |
| [LangChain](https://python.langchain.com) | Фреймворк для агентов (Python) | ⭐⭐⭐⭐ |
| [AutoGen](https://microsoft.github.io/autogen) | Агенты от Microsoft (Python) | ⭐⭐⭐ |
| [OpenClaw](https://openclaw.ai) | Готовый агент-ассистент с памятью | ⭐ |

### Архитектура агента
```
Задача → Планирование → Инструменты → Действие → Результат
                ↑__________________________|
                        (цикл)
```

**Компоненты:**
- **LLM** — мозг агента (GPT-4, Claude, Gemini)
- **Tools** — что умеет: браузер, файлы, API, код
- **Memory** — что помнит: краткосрочная и долгосрочная
- **Planning** — как разбивает задачу на шаги

### Ресурсы
- 📖 [LangChain Docs](https://python.langchain.com/docs)
- 📖 [CrewAI Docs](https://docs.crewai.com)
- 🎥 YouTube канал: Matt Wolfe, AI Jason, David Ondrej
- 🎥 YouTube: "Build AI Agents 2025 (no code)"

### Практическое задание
1. Создай агента который мониторит вакансии и присылает подборку
2. Настрой агента для анализа конкурентов по заданным сайтам
3. Сделай мульти-агентную систему: один ищет, другой анализирует, третий пишет отчёт

## 💡 Принципы быстрого обучения
1. **Сразу на практике** — не читай всё, пробуй руками
2. **Один инструмент → один реальный проект** — не распыляйся
3. **Документируй что работает** — веди свою базу промптов
4. **Учись на кейсах** — ищи "как сделали X с помощью AI"
5. **Комьюнити** — вопросы в Discord/Telegram быстро закрывают пробелы
