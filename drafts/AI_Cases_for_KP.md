## 1. Logera — Помощник Проектного Руководителя

### Задача

Автоматизировать рутинные задачи проектного руководителя: транскрипция встреч, анализ документов, генерация отчётов, работа с базой знаний проекта. Критичное требование — полная локальность для обеспечения конфиденциальности корпоративных данных.

### Срок разработки

**7 месяцев** (июль 2025 — февраль 2026)

### Конечный продукт

**Веб-приложение (production-ready):**
- Frontend: Svelte-приложение с интерактивным UI
- Backend: FastAPI + 7 микросервисов-воркеров (media prep, ASR, diarization, speaker linking, indexer, NLP, cleanup)
- Архитектура: Multi-tier микросервисная система с очередями (RabbitMQ), векторной БД (Qdrant), полнотекстовым поиском (OpenSearch), объектным хранилищем (MinIO)
- Статус: Оптимизирован и готов к внедрению

### Решение

**Обработка аудио/видео:**
- **Транскрипция + диаризация:** OpenAI Whisper + pyannote.audio/WhisperX — автоматическое распознавание речи с разделением по спикерам. Часовое видео обрабатывается за ~2 минуты.
- **Идентификация спикеров:** Person Candidates — автоматическое распознавание людей по голосу из истории встреч.
- **Оптимизация производительности:** Время загрузки ASR сокращено на 80-90% благодаря оптимизированным workers.

**AI и база знаний:**
- **RAG + векторный поиск:** Qdrant (векторная БД) + OpenSearch (полнотекстовый поиск) — "память" системы о проекте, контекстный поиск, автоматическая генерация саммари по встречам.
- **LLM через LiteLLM:** Гибкий прокси для работы с разными LLM-провайдерами (OpenAI, Anthropic, локальные модели).
- **LLM-чат с базой знаний:** Интерактивный диалог с AI, имеющим доступ ко всем документам и транскриптам проекта через RAG.

**Работа с документами:**
- **Чтение:** Универсальный парсинг PDF (pypdf), DOCX (python-docx), изображения (Tesseract OCR).
- **PDF Viewer:** Встроенный просмотр PDF-документов с подсветкой цитат.
- **Редактирование WORD:** OnlyOffice Document Editor + TipTap — профессиональное редактирование в браузере.
- **AI-редактирование через чат:** LangGraph + Office.js API — AI генерирует JavaScript код для автоматического редактирования документов в OnlyOffice (вставка текста, таблиц, форматирование, замена секций). Пользователь управляет документом через естественный язык.

**Оптимизация и production-ready:**
- **Хранилище:** Оптимизация снизила расход места на 84% (65 MB → 10.5 MB на файл)
- **Cleanup Worker:** Автоматическая очистка временных файлов
- **Multi-tenant:** Изоляция данных организаций, tenant-based доступ

### Моя роль

PM + Full-Stack Developer + AI Architect — проектирование архитектуры, разработка frontend/backend, интеграция AI-компонентов, оптимизация производительности, управление проектом.

### Результаты

- **Производительность:** 1 час видео → 2 минуты обработки (транскрипция + диаризация + саммари)
- **Экономия времени:** Вместо 30-60 мин ручного конспектирования — автоматическая обработка + готовый протокол
- **Оптимизация хранилища:** -84% расход места, -92% количество объектов
- **Оптимизация CPU:** -50-66% нагрузка при обработке
- **Полностью локальное решение** — критично для корпоративного сектора
- **Production-ready** — оптимизирован, масштабируем, готов к внедрению

### Технологический стек

**Backend:** Python, FastAPI, LangGraph, LangChain, LiteLLM, RabbitMQ (AMQP), Redis, PostgreSQL, Peewee ORM

**AI/ML:** Whisper, pyannote.audio, Qdrant (векторная БД), OpenSearch, LiteLLM

**Frontend:** Svelte, TipTap Editor, OnlyOffice Document Editor, Office.js API

**Infrastructure:** Docker, Nginx, MinIO (S3), Prometheus, Grafana

## 2. sales-coach — AI-симулятор для тренировки продажников

### Задача

Создать онлайн-тренажёр для отработки навыков холодных и тёплых продаж в безопасной среде, где AI играет роль клиента с настраиваемым поведением.

### Срок разработки

**4.5 месяца** (ноябрь 2024 — март 2025)

### Конечный продукт

**Веб-приложение с real-time функционалом:**
- Frontend: Svelte-приложение для интерактивной симуляции звонков
- Backend: NestJS WebSocket Gateway (ws-speaker) для real-time аудио-потоков
- Статус: Работающий прототип (стартап заглох, но технически функционирует)

### Решение

- **Real-time симуляция звонков:** AI выступает в роли потенциального клиента с настраиваемым поведением: холодный/тёплый лид, уровень возражений, заинтересованность.

- **WebSocket архитектура:** NestJS WebSocket Gateway (ws-speaker) — обработка аудио-потоков в реальном времени без задержек.

- **STT/TTS:** Yandex Cloud Speech Kit — распознавание речи продавца и синтез голоса AI-клиента.

- **Динамическая генерация промптов:** Адаптивная сборка контекста на основе параметров симуляции — AI ведёт себя естественно и непредсказуемо.

- **Геймификация:** Задача продавца — убедить AI купить (не так просто, как кажется!)

### Моя роль

Full-Stack Developer + AI Architect — проектирование архитектуры, разработка WebSocket-сервера, интеграция Speech API, разработка логики динамических промптов.

### Результаты

- Работающий прототип с real-time симуляцией
- Технически сложное решение — real-time AI + динамический контекст
- Демонстрирует экспертизу в WebSocket, STT/TTS, динамических промптах

### Технологический стек

NestJS, WebSocket, Svelte, Yandex Cloud Speech Kit, LLM (динамические промпты), Drizzle ORM, Docker

### Статус

Стартап заглох, но технически проект работает
