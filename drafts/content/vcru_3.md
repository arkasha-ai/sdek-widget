# Rate limit, concurrency и другие слова которые сломали нам субботу

Мы делали генератор карточек для маркетплейсов. Бэкенд готов, модель работает, первые карточки красивые. Осталось масштабировать. И тут всё остановилось.

Replicate — платформа для запуска ML-моделей через API. Удобно, быстро, не надо поднимать свои GPU. Мы прочитали документацию. Rate limit — есть, но вроде нормальный. Запустились. Работает.

Потом два пользователя попробовали генерировать одновременно. Один из них завис. Второй получил результат через минуту вместо десяти секунд.

Полезли разбираться. Оказалось: rate limit у Replicate — это не RPM (requests per minute). Это concurrency. Два параллельных запроса. Не два в секунду, не двести в минуту. Два одновременно. Точка.

Почему это принципиально разный тип проблемы? RPM можно обойти задержками. Шлёшь запрос, ждёшь секунду, шлёшь следующий. Все обслуживаются, просто не мгновенно. Concurrency означает что третий запрос физически ждёт пока один из двух не закончится. Если генерация занимает 15 секунд — третий пользователь ждёт 15 секунд. Четвёртый — 30.

Начали искать альтернативы. fal.ai — первый кандидат. API другой, но вроде бы быстрее и дешевле. Зарегистрировались, читаем доки. В основном endpoint нет параметра для входного изображения. Вообще нет. Для текст-в-картинку — да. Для "вот фото товара, нарисуй вокруг него красивую сцену" — нет.

Перерыли всё. Нашли отдельный endpoint `/edit` с параметром `image_urls`. Работает. Но поведение модели другое — одна и та же модель на Replicate и на fal.ai генерирует разные результаты. Куртка на fal.ai возвращалась с изменёнными деталями. Та же модель, другая платформа, другой результат. Добро пожаловать в мир ML-инференса.

Together AI — посмотрели. Vertex AI — посмотрели. У всех есть лимиты. Просто разные. Кто-то лимитирует по RPM, кто-то по concurrency, кто-то по GPU-часам. Слово "unlimited" в маркетинговых материалах означает "unlimited до определённого предела".

Чему научились за эту субботу: читайте не документацию, а раздел pricing/limits. И не маркетинговую страницу, а API reference. Там мелким шрифтом написано то, что вы узнаете на проде в субботу вечером.
