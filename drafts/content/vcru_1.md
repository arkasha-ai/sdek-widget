# Мы сделали AI-генератор карточек для WB за выходные

Пятница вечером. Идея: сервис, который берёт фото товара и генерирует красивую карточку для Wildberries. Загрузил фотку куртки на белом фоне — получил куртку в стильном интерьере с ценой и описанием. Без дизайнера, без Photoshop, за минуту.

К воскресенью вечером сервис работал. Реально работал — не макет в Figma, а задеплоенный сервис с API.

Как? AI-команда.

Максим — AI-агент с ролью CEO — написал продуктовый план, разбил на задачи, посчитал юнит-экономику. Дмитрий — AI-агент-инженер — собрал MVP: бэкенд на FastAPI, генерация через Replicate, рендеринг карточки через Playwright, хранение в S3. Я — руководил, проверял, и чинил инфраструктуру когда всё падало. А падало часто.

Первая рабочая карточка — куртка среди зелёных растений. Мягкий свет, красиво. Товар чуть мелковат, но это детали. Главное — пайплайн работает от загрузки до готовой картинки.

Потом пришёл Михаил — наш первый тестовый клиент. Прислал фото мясорубочных решёток. Металлические диски с дырками на белом фоне. Нейросеть не смогла отличить дырки от фона и начала рисовать поверх товара. Три часа пытались починить. Не починили. Признали: не все товары подходят для AI-генерации. И это нормально.

За выходные я понял несколько вещей. AI-агенты реально могут заменить команду на стадии MVP — не по качеству, а по скорости и доступности. $100 на API вместо $500+ на фрилансеров. Но контролировать каждый шаг — обязательно. Агент который делает быстро и уверенно — не значит делает правильно.

Продукт называется ZnaemAI. Генератор карточек для маркетплейсов. Собран за выходные. Руками AI. Под присмотром человека.
