### Оптимальный состав

- **Phase 1 (6–8 нед.):** ML-инженер + Backend + Frontend + DevOps (часть) = 3–4 человека
- **Phase 2 (8–10 нед.):** Backend + Frontend + ML-инженер (часть) + QA = 3–4 человека
- **Phase 3 (4–6 нед.):** DevOps + QA + Backend (часть) = 2–3 человека

**Минимальная команда:** 3 человека (Backend/ML совмещение + Frontend + DevOps/QA совмещение) → срок увеличивается до 28–32 недель.

**Оптимальная команда:** 4 человека → 20–24 недели.
