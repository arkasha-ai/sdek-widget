О проекте
Задача, контекст и наше решение
Задача клиента
Фармацевтический холдинг с международными партнёрами (RU / EN / HI / ZH). Переговоры, конференции, рабочие встречи — всё требует синхронного перевода в реальном времени. Облачные сервисы исключены: коммерческая тайна и требование on-premise развёртывания.
Наше решение
SyncVoice™ — on-premise платформа синхронного перевода на базе . Работает полностью внутри инфраструктуры клиента. Латентность перевода — 1–3 секунды, поддержка 4 языков, специализированные глоссарии фармацевтической терминологии. Ни один байт речи не покидает периметр компании.
Ключевые характеристики
On-Premise
Данные не покидают периметр компании. Полное соответствие требованиям ИБ и коммерческой тайне.
Real-Time
Латентность синхронного перевода — 1–3 секунды. Живой разговор без задержек.
4 языка
Русский, английский, хинди, мандаринский китайский. Все направления перевода.
Глоссарии
Специализированная фарм-терминология. 2 000+ терминов, импорт CSV/Excel, CRUD.
White Label
Логотип, цвета, название и домен клиента. Полная кастомизация интерфейса через административную панель.

Сценарии использования
Три ключевых режима работы платформы
Сценарий 01
Конференц-залы (In-Room)
Физические микрофоны участников передают аудиопоток в систему. Каждый участник сканирует QR-код и получает перевод в наушники на выбранном языке. Постоянные залы с предварительной настройкой языкового профиля для каждого места — участники приходят и сразу работают.
QR-доступ Постоянные залы Языковые профили мест
Сценарий 02
Видеоконференции
Встроенная видеозвонилка — без сторонних сервисов. Участники подключаются через браузер по ссылке, перевод работает в реальном времени прямо внутри платформы. Все данные остаются на серверах клиента.
On-Premise Браузерный клиент Real-Time
Сценарий 03
Запись сессий
Автоматическая запись встреч в формате MP4 с раздельными аудиодорожками для каждого языка. При воспроизведении участник выбирает нужный язык. Гибкая политика хранения: настройка периода хранения, автоудаление по расписанию, защита от несанкционированного доступа.
MP4 Раздельные аудиодорожки Политика хранения Автоудаление
