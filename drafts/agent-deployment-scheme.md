# Автоматизация деплоя агентов под пользователей

## Что входит в "пакет одного агента"

```
agent-template/
├── openclaw.json          ← конфиг (бот токен, модель, каналы)
├── workspace/
│   ├── SOUL.md            ← личность агента (шаблон)
│   ├── USER.md            ← данные пользователя (имя, часовой пояс, приоритеты)
│   ├── AGENTS.md          ← правила поведения
│   ├── IDENTITY.md        ← имя и vibe агента
│   └── memory/            ← пустая папка для памяти
└── .env                   ← API ключи (LiteLLM, токены)
```

## Схема деплоя (Docker + Dokploy)

```
Новый клиент
     │
     ▼
1. Онбординг-форма (Telegram или веб)
   - Имя пользователя
   - Часовой пояс
   - Имя агента
   - Приоритеты (здоровье? задачи? рабочие напоминалки?)
     │
     ▼
2. Скрипт генерации конфига (Python)
   - Создаёт папку agent-{username}/
   - Заполняет USER.md по шаблону
   - Вставляет токен бота
   - Создаёт отдельный LiteLLM ключ с лимитом бюджета
     │
     ▼
3. Dokploy API → создаёт новое приложение
   - Docker image: openclaw (наш кастомный)
   - ENV: BOT_TOKEN, LITELLM_KEY, USER_NAME, TIMEZONE
   - Volume: /workspace/agent-{username}/
   - Домен: agent-{username}.znaem.ai (опционально)
     │
     ▼
4. Первый запуск
   - Агент пишет пользователю: "Привет! Я {имя}, твой агент. Давай познакомимся."
   - Проводит онбординг-интервью (5 вопросов)
   - Заполняет USER.md и MEMORY.md начальными данными
```

## Технически: что автоматизируется

| Шаг | Сейчас | После автоматизации |
|-----|--------|---------------------|
| Создать бота | Руками в @BotFather | API BotFather (или pre-created пул токенов) |
| Сгенерировать конфиг | Руками копировать файлы | Python скрипт `create_agent.py --user Иван --tz Moscow` |
| Задеплоить | Руками в Dokploy UI | `dokploy-app deploy` через API |
| LiteLLM ключ с лимитом | Руками | LiteLLM API `POST /key/generate` с `max_budget` |
| Онбординг пользователя | Вручную объяснять | Агент сам проводит через чат |

## LiteLLM бюджет на пользователя

```python
# Создать ключ с лимитом $100 (= 10к₽ примерно)
POST /key/generate
{
  "max_budget": 100,
  "budget_duration": "monthly",
  "key_alias": "user-ivan",
  "models": ["claude-sonnet", "gpt-4o", "qwen"]
}
```

Когда кончается — автоматический алерт пользователю и нам.

## MVP план (что делаем сейчас для 5 человек)

**Полуавтомат (1-2 дня работы):**
1. Скрипт `create_agent.py` — генерирует папку с конфигом
2. Docker Compose шаблон — один файл, меняем ENV
3. Деплой руками через Dokploy UI (5 минут на пользователя)
4. LiteLLM ключ руками с лимитом

**Полный автомат (потом, когда поток больше):**
- Веб-форма онбординга
- Webhook → автодеплой
- Личный кабинет пользователя (статус агента, баланс токенов)

## Стоимость для нас

| Статья | Стоимость |
|--------|-----------|
| Сервер (VPS 4CPU/8GB) | ~1500₽/мес (держит 10-15 агентов) |
| LiteLLM токены | себестоимость ~3-5к₽ при бюджете 10к₽ (маржа 2x) |
| Наше время на деплой | 30 мин на клиента (MVP) |

Итого с 5 клиентов: **50к₽/мес** при затратах ~15-20к₽.
