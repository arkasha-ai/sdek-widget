## Общее описание

SAMP Analytics — это профессиональный SaaS-сервис для аналитики маркетплейса Wildberries. Аналог Wildbox.ru / MPStats. Работает на основе данных MPStats API и Wildberries API. Предназначен для продавцов WB, которые хотят анализировать свои товары, конкурентов, категории, управлять поставками и рекламой.

**Слоган:** «Профессиональная аналитика для Wildberries»

**Навигационное меню (левый сайдбар):**
- 📊 Дашборд (`/dashboard`)
- 📦 Анализ товара (`/product-analysis`)
- 🏢 Анализ бренда (`/brand-analysis`)
- 🏪 Анализ продавца (`/supplier-analysis`)
- 📂 Анализ категорий (`/category-analysis`)
- 📅 Анализ сезонности (`/seasonality-analysis`)
- 🤖 ИИ помощник (`/ai-helper`)
- 🧠 Оракул запросов (`/oracle-queries`)
- 🚚 План поставок (`/supply-planning`)
- 👥 Поиск блогеров (`/blogger-search`)
- 📢 Мониторинг рекламы (`/ad-monitoring`)
- 🌐 Глобальный поиск (`/global-search`)
- 👤 Профиль (`/profile`)

**Хедер (верхняя панель):**
- Кнопка «☰» — сворачивание/разворачивание сайдбара
- Название текущей страницы + подзаголовок
- Ссылка на профиль: отображает email, баланс, тип подписки
- Кнопка «🚪 Выйти» — выход из аккаунта

## 2. Анализ товара (`/product-analysis`)

**Назначение:** Детальный анализ любого товара Wildberries по артикулу. Главный инструмент сервиса — получение полной аналитики по конкретному товару в реальном времени.

### Элементы UI (форма поиска):
- **Текстовое поле:** «Введите артикул товара Wildberries (например: 140247993)»
- **Кнопка:** «🚀 Анализировать»

### Информационный блок (до запроса):
**💡 Важные рекомендации для поиска товара:**
- Правильный формат артикула: только цифры, без пробелов (`307351497`, а не `307 351 497` или `WB-307351497`)
- Как найти артикул: в URL страницы WB после `/catalog/`, или в разделе «Подробнее» в мобильном приложении

## 3. Анализ бренда (`/brand-analysis`)

**Назначение:** Комплексная аналитика бренда с использованием MPStats API. Позволяет изучить все товары бренда, их продажи, динамику и рыночную позицию.

### Элементы UI:
- **Текстовое поле:** «Название бренда» (placeholder: «Например: Mango, Zara, H&M»)
- **Выпадающий список «Период»:** 7 дней / 14 дней / 30 дней / **90 дней** (по умолчанию)
- **Выпадающий список «FBS»:** **Все товары** / Только FBS
- **Выпадающий список «Новинки»:** **Все товары** / За 7 дней / За 14 дней / За 30 дней
- **Кнопка:** «🔍 Анализировать»

### Информационный блок (рекомендации):
**💡 Важные рекомендации для анализа бренда:**
- Правильное написание: точно как на Wildberries, без лишних символов (`Mango` или `Zara`, не `Mango Store` или `Zara Home`)
- Рекомендуемый период: 90 дней (короткие периоды дают неточные данные)
- Настройки фильтров: FBS «Все товары» + Новинки «Все товары»
- Если анализ не дает результатов: изменить период, проверить написание, попробовать другие настройки FBS/новинок

### Функциональность:
- Запрос к MPStats API по названию бренда
- Анализ всего ассортимента за выбранный период
- Фильтрация по схеме FBS (Fulfillment by Seller) и статусу новинок
- Предположительно выводит: список товаров бренда, продажи, выручку, динамику

### Связи с другими разделами:
- Переход из `/product-analysis` при клике на бренд товара
- Связан с `/supplier-analysis` (бренд и продавец могут отличаться)

## 4. Анализ продавца (`/supplier-analysis`)

**Назначение:** Детальный анализ продавца (поставщика) на Wildberries через MPStats API. Полная аналитика товаров конкретного продавца.

### Элементы UI:
- **Текстовое поле «Название продавца»** (текущее значение: «ИП Золтоев А А»)
  - placeholder: «ИП Золтоев А А, ООО Остин, Индивидуальный предприниматель Золтоев Артур Арсаланович...»
- **Поле «Дата начала»** (по умолчанию: 2026-01-17, т.е. месяц назад)
- **Поле «Дата окончания»** (по умолчанию: 2026-02-17, т.е. сегодня)
- **Выпадающий список «FBS фильтр»:** Все товары / **Только FBS** / Только FBO
- **Выпадающий список «Новинки»:** **Все товары** / Новинки за 7 дней / За 14 дней / За 30 дней
- **Кнопка:** «🔍 Анализировать продавца»

### Быстрые варианты (кнопки для вставки примеров):
- «ИП Золтоев А А»
- «ООО Остин»
- «Индивидуальный предприним...»
- «Золтоев АА»

### Информационный блок (рекомендации):
**💡 Важные рекомендации:**
- Название продавца ≠ название бренда (может отличаться)
- Как найти имя продавца: на странице товара WB, значок «i» справа от имени → полное юридическое наименование
- Примеры правильных названий: «ИП Золтоев А А», «ООО Остин»
- Возможные проблемы: продавцы могут скрывать данные, использовать псевдонимы

### Связи с другими разделами:
- Переход из `/product-analysis` при клике на имя продавца
- Связан с `/brand-analysis` (один продавец может иметь несколько брендов)

## 5. Анализ категорий (`/category-analysis`)

**Назначение:** Детальная аналитика категорий Wildberries с интеллектуальными рекомендациями. Позволяет исследовать конкретную нишу/категорию и понять её потенциал.

### Элементы UI:
- **Текстовое поле «Путь категории»** (placeholder: «Спорт, Красота, Дом»)
  - Формат: `Мужчинам/Одежда/Худи` или `Женщинам/Одежда/Платья`
- **Поле «Дата от»** (по умолчанию: месяц назад)
- **Поле «Дата до»** (по умолчанию: сегодня)
- **Выпадающий список «FBS»:** **Все товары** / Только FBS
- **Кнопки быстрого выбора периода:** 7 дней / 14 дней / 30 дней / 90 дней
- **Кнопка:** «🔍 Анализировать категорию»

### Информационный блок (рекомендации):
**💡 Важные рекомендации:**
- Для категорий одежды: обязательно указывать пол в начале пути (`Мужчинам/Одежда/Худи`)
- Не использовать пробелы вокруг `/` (правильно: `Мужчинам/Одежда/Худи`, неправильно: `Мужчинам / Одежда / Худи`)
- Путь должен точно соответствовать категориям на Wildberries.ru
- Если результатов нет: попробовать более ранние даты (например, 2021 год)

### Функциональность:
- Запрос к MPStats API по пути категории
- Анализ за выбранный период с фильтрацией по FBS
- Быстрые кнопки для стандартных периодов (7/14/30/90 дней)
- Предположительно выводит: топ товаров в категории, средние цены, объём продаж, динамику

### Связи с другими разделами:
- Переход из `/product-analysis` при клике на категорию товара
- Связан с `/seasonality-analysis` (анализ сезонности по той же категории)

## 6. Анализ сезонности (`/seasonality-analysis`)

**Назначение:** Исследование сезонных паттернов продаж, выручки и ассортимента по категориям товаров. Помогает понять, когда лучше продавать тот или иной товар.

### Элементы UI:
- **Текстовое поле «Категория товаров»** (предзаполнено: «Для женщин/Одежда/Платья»)
  - placeholder: «Например: Для женщин/Одежда/Платья»
- **Выпадающий список «Период анализа»:** **День** / Неделя / Месяц
- **Выпадающий список «Показатель»:**
  - 💰 Выручка (по умолчанию)
  - 📦 Продажи
  - 🎯 Ассортимент
- **Чекбокс «🎄 Показать влияние праздников»** (включён по умолчанию)
- **Кнопка:** «🚀 Анализировать сезонность»

### Функциональность:
- Анализирует выбранный показатель (выручка/продажи/ассортимент) за всё доступное время
- Показывает сезонные всплески и спады
- Опционально отмечает влияние праздников (Новый год, 8 марта, 14 февраля и т.д.)
- Детализация: по дням, неделям или месяцам

### Данные/метрики:
- Динамика выручки/продаж/ассортимента по времени
- Сезонные паттерны и пики
- Влияние праздников на продажи

### Связи с другими разделами:
- Использует те же пути категорий что и `/category-analysis`
- Помогает планировать поставки → `/supply-planning`

## 7. ИИ помощник (`/ai-helper`)

**Назначение:** Генерация продающего контента для товаров Wildberries с помощью нейронной сети. Аналог функций Telegram-бота SAMP в веб-интерфейсе.

### Элементы UI:
- **Выпадающий список типа контента:**
  - **Описание товара** (по умолчанию)
  - Карточка товара
  - Продающий текст (AIDA)
  - Рекламный текст
  - Пост для соцсетей
  - Email-рассылка
  - Структура лендинга
  - SEO-контент
- **Текстовое поле:** «Опишите, что сгенерировать...»
- **Кнопка:** «Сгенерировать»

### Инструкция пользователю:
1. Выберите тип контента в выпадающем списке
2. В поле ниже опишите задачу или товар (например: «Описание для спортивной бутылки 650 мл»)
3. Нажмите «Сгенерировать» — текст появится ниже

### Функциональность:
- Генерирует текстовый контент 8 различных типов
- Принимает свободное описание задачи на русском языке
- Выводит результат прямо на странице (под формой)
- Аналогично Telegram-боту сервиса

### Связи с другими разделами:
- Счётчик «Помощи от ИИ» на дашборде
- Результаты генерации отображаются в «История операций» в профиле

## 8. Оракул запросов (`/oracle-queries`)

**Назначение:** Интеллектуальный анализ поисковых запросов на Wildberries с AI-рекомендациями. Позволяет найти прибыльные ниши и тренды по поисковым запросам.

### Элементы UI:
- **Выпадающий список «Количество категорий»:** 5 / 7 / **10** / 12 / 15 категорий (по умолчанию 10)
- **Поле «Месяц анализа»:** выбор месяца (по умолчанию July 2025)
- **Числовое поле «Мин. выручка (₽)»:** 10000 (по умолчанию)
- **Числовое поле «Мин. частотность»:** 100 (по умолчанию)
- **Выпадающий список «Тип анализа»:**
  - 🔍 По запросам (по умолчанию)
  - 📦 По товарам
  - 🏷️ По брендам
  - 🤝 По поставщикам
  - 📂 По категориям
- **Кнопка:** «🧠 Запустить анализ оракула»

### Функциональность:
- Анализирует поисковые запросы/товары/бренды/поставщиков/категории за выбранный месяц
- Фильтрует по минимальной выручке и частотности
- Возвращает топ N категорий/запросов по выбранным параметрам
- AI формирует рекомендации по найденным данным
- Полезен для поиска незанятых прибыльных ниш

### Связи с другими разделами:

## 9. План поставок (`/supply-planning`)

**Назначение:** Расчёт плана поставок на основе реальных данных продаж за 30 дней (MPStats API). Помогает избежать out-of-stock и переизбытка товаров.

### Элементы UI:
- **Текстовое поле «SKU (артикул)»** — ввод артикула товара Wildberries
- **Числовое поле «Время доставки (дни)»** — по умолчанию 7 дней
- **Числовое поле «Страховой запас (дни)»** — по умолчанию 3 дня
- **Числовое поле «Закупочная цена (₽)»** — по умолчанию 0₽
- **Кнопка:** «🔍 Анализировать план поставок»

### Функциональность:
- Получает данные о продажах товара за последние 30 дней
- Рассчитывает среднедневные продажи
- Учитывает время доставки до склада WB + страховой запас
- Рассчитывает оптимальный объём поставки
- При указании закупочной цены — расчёт рентабельности
- Результаты предположительно включают: рекомендуемый объём, дату следующей поставки, оборачиваемость

### Входные параметры для расчёта:
| Параметр | Описание |
|----------|----------|
| SKU | Артикул товара WB для получения данных продаж |
| Время доставки | Сколько дней товар едет от поставщика до склада WB |
| Страховой запас | Буфер дней на случай задержек |
| Закупочная цена | Для расчёта экономики поставки |

### Связи с другими разделами:
- Переход из `/product-analysis` при клике на остаток товара
- Использует те же артикулы что и анализ товара

## 12. Глобальный поиск (`/global-search`)

**Назначение:** Поиск и анализ упоминаний товаров в социальных сетях и медиа. Позволяет отслеживать, как блогеры и пользователи говорят о товаре.

### Элементы UI:
- **Текстовое поле:** «Введите артикул товара или название бренда...»
- **Кнопка:** «Найти»
- Пример использования: `176409037` или `ZARA`

### Возможности поиска:
- Поиск по артикулу товара
- Поиск по названию бренда
- Анализ рекламных размещений
- Оценка эффективности публикаций

### Метрики анализа:
- **Охват и вовлеченность** — сколько пользователей увидело публикацию
- **Влияние на продажи** — как упоминания коррелируют с продажами
- **Рост заказов после рекламы** — динамика после выхода рекламного контента
- **Эффективность площадок** — какие платформы дают лучший результат

### Связи с другими разделами:
- Связан с `/blogger-search` — после нахождения блогеров
- Связан с `/ad-monitoring` — комплексный мониторинг рекламы
- Результаты могут вести к `/product-analysis` для конкретных товаров

│   ├── /brand-analysis — анализ бренда

- **AI/LLM** — генерация контента (ИИ помощник), рекомендации
