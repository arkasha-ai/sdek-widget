## Что надо делать

**Объект:** Проектирование и разработка **универсальной информационно-библиотечной системы** (ОКПД2: 62.01.11.000)

**Заказчик:** ФГАУ «НМИЦ нейрохирургии им. академика Н.Н. Бурденко» Минздрава России
г. Москва, ул. 4-ая Тверская-Ямская, д. 16

**Суть системы:**
Современная микросервисная платформа для централизованного хранения, каталогизации, интеллектуального поиска и просмотра документов (в первую очередь PDF).

**Три этапа:**
1. **Viewer** — React-компонент на базе PDF.js: просмотр PDF, навигация, масштабирование, аннотирование (highlights, комментарии), темы, полноэкран. Срок: не указан явно (в рамках 70 дней).
2. **Core Platform** — инфраструктура (PostgreSQL, MinIO, Redis), Auth Service + API Gateway, Document Storage Service, Collections/Tags/Sharing, Frontend (React SPA), базовый Processing (thumbnails). Полноценная платформа для загрузки, хранения, просмотра документов.
3. **Интеграция с АБИС Ирбис64+** — адаптер IntegraLink↔Ирбис, единое поисковое окно (запрос в Ирбис → результаты в интерфейсе системы), синхронизация ссылок в поле 951 MARC-записи.

**Технический стек:**
- Backend: Node.js 20+, TypeScript 5+, Fastify
- Frontend: React 19+, Vite, Tailwind CSS
- БД: PostgreSQL, MinIO (S3), Redis
- Инфраструктура: Docker Swarm, Loki+Promtail+Grafana
- Интеграции: АБИС Ирбис64+, IntegraLink (ESB), Active Directory (OIDC/SAML SSO)

**Срок реализации:** 70 календарных дней с момента подписания договора

**Поддержка:** До конца 2026 года включительно

**Документация:** HLD, ER-диаграммы, OpenAPI 3.0 (Swagger), руководства пользователя/администратора, результаты тестов

**Приёмка:** Поэтапная (акт по каждому этапу) + итоговый акт GO-LIVE после UAT

**Права:** Простая (неисключительная) лицензия заказчику — без права распространения, модификации, сублицензирования
