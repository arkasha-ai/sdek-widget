# Сравнение моделей OpenClaw

*Анализ доступных LLM моделей и их применение*

## Обзор

OpenClaw поддерживает **9 настроенных моделей** от различных провайдеров. Все модели доступны через единый интерфейс с алиасами для удобства использования.

**Дефолтная модель:** `anthropic/claude-sonnet-4-5` (алиас: `sonnet`)

## Детальный анализ моделей

### 🏆 **Top Tier - Anthropic Claude**

#### `sonnet` (claude-sonnet-4-5)
- **Провайдер:** Anthropic
- **Контекст:** 195k токенов
- **Возможности:** text+image

**Плюсы:**
- ✅ Высокое качество понимания контекста
- ✅ Поддержка изображений
- ✅ Отличная работа с русским языком
- ✅ Надёжная безопасность и этичность
- ✅ Длинный контекст (195k)
- ✅ **Дефолтная модель OpenClaw**

**Минусы:**
- ❌ Высокая стоимость
- ❌ Может быть медленнее других моделей
- ❌ Требует API ключ Anthropic

**Когда использовать:**
- Критически важные задачи
- Анализ документов с изображениями
- Сложные рассуждения
- Качественные переводы

#### `opus` (claude-opus-4-6)
- **Провайдер:** Anthropic
- **Контекст:** 195k токенов
- **Возможности:** text+image

**Плюсы:**
- ✅ Максимальное качество от Anthropic
- ✅ Поддержка изображений
- ✅ Экспертный уровень анализа
- ✅ Длинный контекст

**Минусы:**
- ❌ Самая высокая стоимость
- ❌ Медленнее Sonnet
- ❌ Избыточна для простых задач

**Когда использовать:**
- Исследовательские задачи
- Сложный код-ревью
- Академический анализ
- Критические бизнес-решения

## 🎯 Рекомендации по использованию

### По задачам:

| Задача | Рекомендуемая модель | Альтернатива |
|--------|---------------------|--------------|
| **Критически важные задачи** | `sonnet` | `opus` |
| **Работа с кодом** | `coder` | `coder-next` |
| **Быстрая обработка** | `glm47f` | `minimax` |
| **Длинные документы** | `glm47f` | `glm47` |
| **Анализ изображений** | `sonnet` | `opus` |
| **Экономичные задачи** | `minimax` | `qwen` |
| **Мультиязычность** | `qwen` | `sonnet` |
| **Исследования** | `opus` | `qwen` |

### По приоритетам:

#### 🏆 **Премиум качество**
```
opus → sonnet → qwen
```

#### ⚡ **Скорость**
```
glm47f → minimax → coder-next
```

#### 💰 **Экономичность**
```
minimax → qwen → glm47f
```

#### 🔧 **Специализация**
```
coder/coder-next (код) → sonnet/opus (изображения) → glm47f/glm47 (длинные тексты)
```

## 🔐 Аутентификация

### Поддерживаемые провайдеры:
- **Anthropic:** Требует `sk-ant-*` ключ
- **LiteLLM:** Использует общий ключ `sk-gDi9O...`
- **MiniMax:** Использует LiteLLM ключ

### Настройка:
```bash
# Проверить статус моделей
openclaw models status

# Просмотреть алиасы
openclaw models aliases

# Настроить дефолтную модель
openclaw models set <алиас>
```

## 💡 Выводы

1. **Claude Sonnet** - лучший универсал для большинства задач
2. **Coder модели** - незаменимы для программирования  
3. **GLM Flash** - отличны для скорости и длинных текстов
4. **MiniMax** - хорошая экономичная альтернатива
5. **Qwen** - баланс качества и производительности

**Рекомендация:** Используйте `sonnet` как основную модель, `coder` для кода, и `glm47f` для быстрых задач или длинных документов.
