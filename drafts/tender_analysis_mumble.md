## 🎯 ПРЕДМЕТ ЗАКУПКИ (из ТЗ)

### Цель проекта
Разработать (или сконфигурировать) **кроссплатформенное мобильное приложение** для голосовой связи на базе **Mumble** для iOS и Android.

### Ключевые требования

**1. Функционал:**
- Режим работы «закрытый микрофон» (по умолчанию микрофон **включен**, кнопка **Mute** отключает его)
- Голосовая связь в режиме **постоянной передачи** (Continuous Transmission)
- Связь через центральный сервер (внутри корпоративной Wi-Fi сети)
- Текстовые сообщения и файлы — опционально (низкий приоритет)

**2. Технические требования:**
- **Платформы:** iOS 15+, Android 10+
- **Транспорт:** TCP (управление) + UDP (голос)
- **Кодек:** Opus с адаптивным битрейтом
- **Шифрование:** TLS/DTLS
- **Задержка:** < 50 мс в локальной сети
- **Масштабируемость:** до нескольких сотен сотрудников
- **Фоновая работа:** приложение должно работать при заблокированном экране

**3. UX/UI:**
- Крупная кнопка **Mute** (не менее 10% площади экрана)
- Звуковой сигнал при вкл/выкл Mute
- Список каналов (отделов) и участников
- Индикатор активности говорящих
- Минималистичные настройки

**4. Варианты реализации (из ТЗ):**
- **Вариант А (быстрый старт):** Кастомизация open-source клиента Mumble с заменой PTT на Mute
- **Вариант Б (полный контроль):** Разработка с нуля на libmumble

**5. Серверная часть:**
- Развёртывание **Murmur** сервера внутри корпоративной сети
- Настройка постоянных каналов по отделам
- Логирование событий
