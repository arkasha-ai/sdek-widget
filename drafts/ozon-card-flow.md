# OZON Premium Card Generator — Флоу v0.1

> Цель: AI-сервис для создания карточек товара уровня профессиональной студии

---

## Флоу пользователя

### Шаг 1 — Подготовка товара
- Пользователь присылает фото товара (любой фон)
- Система автоматически вырезает фон через **rembg**
- Сохраняет PNG с прозрачным фоном
- Показывает результат: "Товар готов, вот что получилось 👆"

### Шаг 2 — Сбор требований
Задаём 3-4 вопроса (не больше, чтобы не грузить):
1. **Что продаём?** — название, ключевые характеристики (пример: "зайчик, 10 сказок, 26 песенок")
2. **Для кого?** — ЦА и настроение (пример: "для детей 0-3 лет, тёплое, сказочное")
3. **Сколько карточек?** — и для каких целей (главная, характеристики, эмоции)
4. **Есть референсы?** — конкуренты, вдохновение, запрещённые стили

### Шаг 3 — Подбор стиля и окружения
На основе слов пользователя система:
- Определяет **тематику фона** (сказочный лес / студия / природа / праздник / минимализм)
- Подбирает **цветовую палитру** (тёплая / холодная / пастель / яркая)
- Генерирует **3 варианта описания стиля** и показывает примеры-референсы (текстом + emoji)
- Пользователь выбирает или говорит "другое"

Пример вывода:
```
Предлагаю 3 варианта стиля:
🟣 Сказочный — мягкие фиолетовые тона, звёзды, светящаяся книга
🌅 Тёплый студийный — золотой свет, нейтральный фон, акцент на игрушке  
🌿 Природный — мягкая зелень, летний день, детское настроение
```

### Шаг 4 — Генерация промпта
Система составляет **детальный промпт** для FLUX Kontext Pro:
- Сохранение товара (img2img)
- Описание фона и освещения
- Композиция (товар справа/по центру, пространство для текста)
- Стиль съёмки (коммерческая фотография, мягкий боке)
- Явный запрет: no text, no hands, no child

Промпт сохраняется и показывается пользователю — можно подправить.

### Шаг 5 — Генерация вариантов
- Генерируем **2-4 варианта** с разными seed (разные композиции)
- На каждый автоматически накладываем текст через PIL:
  - Заголовок (Montserrat Bold)
  - Подзаголовок
  - Нижняя плашка с характеристиками
- Отправляем все варианты пользователю: "Выбери один или скажи что доработать"

### Шаг 6 — Финальный пакет
После выбора:
- Уточняем: сколько карточек нужно (1 / 4 / 6 / 8)?
- Для каждой карточки — свой фон и акцент:
  - Карточка 1: главная (максимально красивая)
  - Карточка 2: характеристики (цифры, факты)
  - Карточка 3: эмоциональная (настроение, польза)
  - Карточка 4: преимущества (список)
- Генерируем весь пакет, архивируем, отдаём
