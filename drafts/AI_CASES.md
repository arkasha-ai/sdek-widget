### 1. Logera — Помощник Проектного Руководителя

**Полное название:** Локальный инструмент для автоматической обработки и анализа звонков/документов

**Задача:**  
Автоматизировать рутину PM/руководителя проектов: транскрипция встреч, анализ документов, генерация отчётов, работа с базой знаний проекта.

**Решение:**
- **Транскрипция + диаризация:** OpenAI Whisper + pyannote.audio/WhisperX — автоматическое распознавание речи с разделением по спикерам
- **RAG + локальные LLM:** Ollama + ChromaDB + LangChain — "память" системы о проекте, контекстный поиск, саммари
- **Чтение документов:** PDF (pdfplumber), DOCX (MCP Word Server), OCR (Tesseract) — извлечение информации из любых форматов
- **Генерация + редактирование документов:** MCP Word Document Server + чат-интерфейс — автоматическое создание протоколов встреч, отчётов; редактирование через диалог с AI
- **Чат с базой знаний:** RAG-поиск по всем документам и транскриптам проекта — AI-ассистент с контекстом всего проекта
- **Архитектура:** FastAPI (backend), Vue 3 + shadcn-vue (frontend), PostgreSQL + ChromaDB, Docker

**Моя роль:** PM + Full-Stack Dev + Architect — проектирование архитектуры, разработка, интеграция AI-компонентов

**Результаты:**
- **Производительность:** Часовое видео обрабатывается за ~2 минуты (транскрипция + диаризация + саммари)
- **Экономия времени:** Вместо ручного конспектирования встречи (30-60 мин) — автоматическая обработка + готовый протокол
- Полностью локальное решение — конфиденциальность данных (критично для корпоративного сектора)
- Работающий MVP с UI — можно демонстрировать клиентам

**Технологии:** Python, FastAPI, Vue 3, Whisper, pyannote.audio, Ollama, RAG, ChromaDB, PostgreSQL, Docker

**Репозиторий:** ai-notebook (приватный)  
**Статус:** Работающий pet-проект

### 5. Office-Word-MCP-Server — MCP сервер для работы с Word (stream-based)

**Задача:**  
Существующие MCP-серверы для Word работают только с файлами в локальной файловой системе — AI не может редактировать файлы "на лету", нужен прямой доступ к ФС.

**Решение:**
- **Stream-based архитектура:** Файл передаётся в MCP-сервер → редактируется → возвращается AI
- **Не требует файловой системы:** AI может работать с любыми Word-документами без необходимости их сохранения на сервере
- **Model Context Protocol (MCP):** Стандартизированный интерфейс для AI-ассистентов
- **Функции:** Создание, чтение, форматирование текста, таблицы, заголовки — полноценное редактирование Word

**Моя роль:** Solo Dev — разработка протокола, реализация stream-based обработки, публикация open-source

**Результаты:**
- Публичный open-source проект (GitHub)
- Используется в Logera для генерации и редактирования документов
- Решает ограничение стандартных MCP-серверов

**Технологии:** Python, MCP (Model Context Protocol), python-docx

**Репозиторий:** Office-Word-MCP-Server (публичный)  
**Статус:** Работает, используется в production (Logera)
