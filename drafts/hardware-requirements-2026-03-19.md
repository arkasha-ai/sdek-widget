# Требования к серверному оборудованию — On-Premise AI-продукты

> Документ: v1.0 | Дата: 19.03.2026  
> Все продукты разворачиваются на серверах заказчика (on-premise)

---

## Ключевые допущения

| Параметр | Значение |
|----------|----------|
| **Qwen3-plus** | ~70B параметров, требует ≥140 GB VRAM (FP16) или ≥80 GB (AWQ/GPTQ 4-bit) |
| **Whisper large-v3** | ~1.5B параметров, ~4 GB VRAM |
| **LLM средней мощности** (Sales Coach) | ~7–14B параметров (Qwen3-8B / Qwen3-14B), 8–16 GB VRAM (FP16) |
| **Inference engine** | vLLM / TGI / SGLang |
| **Квантизация** | AWQ 4-bit как baseline для prod, FP16 для максимального качества |

## 1. Logera — Корпоративная база знаний

**Стек:** SvelteKit + FastAPI + PostgreSQL + pgvector + MinIO + Whisper STT + Qwen3-plus (RAG + генерация)

### Архитектура нагрузки

- **Тяжёлый inference** — RAG-запросы с контекстом до 32K токенов
- **STT** — транскрипция аудио/видео (batch, не real-time)
- **Embeddings** — индексация документов в pgvector
- **Storage** — MinIO для файлов (документы, аудио, видео)

### Конфигурации

| Компонент | 🟡 Минимум (тест/пилот, до 10 юзеров) | 🟢 Рекомендуемая (prod, 50–200 юзеров) |
|-----------|---------------------------------------|----------------------------------------|
| **GPU** | 1× NVIDIA A100 80GB | 2× NVIDIA A100 80GB или 1× NVIDIA H100 80GB |
| **VRAM** | 80 GB (Qwen3-plus 4-bit + Whisper) | 160 GB (Qwen3-plus FP16 + Whisper отдельно) |
| **CPU** | 16 cores (AMD EPYC 7313 / Intel Xeon Gold 5315Y) | 32–64 cores (AMD EPYC 7543 / Intel Xeon Gold 6338) |
| **RAM** | 128 GB DDR4 ECC | 256–512 GB DDR5 ECC |
| **SSD (система + модели)** | 1 TB NVMe PCIe 4.0 | 2× 2 TB NVMe PCIe 4.0 (RAID 1) |
| **HDD/SSD (MinIO хранилище)** | 2 TB SATA SSD | 4–8 TB NVMe или SATA SSD (расширяемое) |
| **PostgreSQL storage** | 500 GB NVMe | 1 TB NVMe (отдельный диск) |
| **Сеть** | 1 Gbit/s | 10 Gbit/s (внутренняя), 1 Gbit/s (внешняя) |
| **БП** | 1600W | 2× 2000W (redundant PSU) |

### Примечания
- Qwen3-plus в 4-bit квантизации (AWQ) помещается на 1× A100 80GB (~40 GB весов + KV-cache)
- Whisper large-v3 занимает ~4 GB VRAM, может работать на том же GPU при 4-bit LLM
- В prod рекомендуется **отдельный GPU для Whisper** при высокой нагрузке на STT
- pgvector с HNSW-индексами потребляет ~2× от размера данных в RAM

## 2. Sales Coach — AI-тренер для менеджеров

**Стек:** Real-time STT (Whisper streaming) + LLM 7–14B + WebSocket + CRM API

### Архитектура нагрузки

- **Real-time STT** — стриминг аудио с задержкой <500 мс
- **LLM inference** — быстрые ответы (latency-critical), контекст до 8K токенов
- **WebSocket** — постоянные соединения (10–100 одновременных сессий)
- **CRM интеграция** — I/O bound, не нагружает GPU

### Конфигурации

| Компонент | 🟡 Минимум (тест, до 5 сессий) | 🟢 Рекомендуемая (prod, 20–50 сессий) |
|-----------|-------------------------------|---------------------------------------|
| **GPU** | 1× NVIDIA RTX 4090 24GB | 1× NVIDIA A6000 48GB или 1× NVIDIA L40S 48GB |
| **VRAM** | 24 GB | 48 GB |
| **CPU** | 8 cores (AMD Ryzen 7 / Intel i7-13700) | 16–32 cores (AMD EPYC 7313 / Xeon Gold 5315Y) |
| **RAM** | 64 GB DDR4 | 128 GB DDR5 ECC |
| **SSD** | 500 GB NVMe | 1 TB NVMe PCIe 4.0 |
| **Сеть** | 1 Gbit/s | 10 Gbit/s (внутренняя) |
| **БП** | 850W | 1200W |

### Распределение VRAM

| Модель | VRAM (FP16) | VRAM (4-bit) |
|--------|-------------|--------------|
| Whisper large-v3 (streaming) | 4 GB | — |
| Qwen3-8B (диалоги) | 16 GB | 6 GB |
| Qwen3-14B (анализ) | 28 GB | 10 GB |
| **Итого (8B + Whisper)** | **20 GB** | **10 GB** |
| **Итого (14B + Whisper)** | **32 GB** | **14 GB** |

### Примечания
- RTX 4090 достаточно для тестов (8B модель + Whisper в 4-bit = ~10 GB)
- Для prod с 14B моделью нужно минимум 48 GB VRAM → A6000 / L40S
- **Latency-критично:** NVMe обязателен, сеть с низким jitter
- Streaming Whisper требует выделенного CPU-потока для буферизации аудио
- Рекомендуется pinning GPU: Whisper на одних SM, LLM на других (через MPS/MIG на A100)

## 3. Персональный AI-агент

**Стек:** Веб-интерфейс + Qwen3-plus LLM + векторная память + интеграции

### Архитектура нагрузки

- **Тяжёлый inference** — Qwen3-plus ~70B, длинный контекст (до 128K токенов)
- **Векторная память** — Qdrant / pgvector, semantic search
- **Интеграции** — API-вызовы, tool use, агентные цепочки
- **Мало юзеров** — 1–5 человек, но высокая нагрузка на GPU

### Конфигурации

| Компонент | 🟡 Минимум (тест, 1–2 юзера) | 🟢 Рекомендуемая (prod, 1–5 юзеров) |
|-----------|------------------------------|--------------------------------------|
| **GPU** | 1× NVIDIA A100 80GB | 1× NVIDIA H100 80GB или 2× A100 80GB |
| **VRAM** | 80 GB | 80–160 GB |
| **CPU** | 8–16 cores | 32 cores (AMD EPYC 7543) |
| **RAM** | 64 GB DDR4 ECC | 128–256 GB DDR5 ECC |
| **SSD** | 1 TB NVMe | 2 TB NVMe PCIe 4.0 |
| **Сеть** | 1 Gbit/s | 1 Gbit/s (не критично — мало юзеров) |
| **БП** | 1200W | 1600W |

### Примечания
- Агентные цепочки (ReAct/tool-use) генерируют последовательные запросы → throughput менее важен, но latency first-token критична
- Длинный контекст (128K) требует большого KV-cache → при FP16 KV-cache может занять 20–30 GB дополнительно
- Векторная память (Qdrant) работает на CPU/RAM, не нагружает GPU

## Совмещение: Logera + AI-агент на одном сервере?

### Вердикт: ⚠️ Возможно, но с ограничениями

| Сценарий | Конфигурация | Работает? |
|----------|-------------|-----------|
| **Оба на 4-bit, разделение по времени** | 1× A100 80GB | ✅ Да, если не одновременно |
| **Оба на 4-bit, одновременно** | 2× A100 80GB | ✅ Да, по GPU на каждый |
| **FP16, одновременно** | 4× A100 80GB или 2× H100 | ✅ Да |
| **Общий LLM-сервер (один инстанс)** | 1× A100 80GB | ✅ Лучший вариант |

### Рекомендация: общий LLM-сервер

Если оба продукта используют **одну и ту же модель** (Qwen3-plus), оптимально:

```
┌─────────────────────────────────────────────┐
│              GPU-сервер                      │
│  vLLM / SGLang → Qwen3-plus (4-bit)        │
│  1× A100 80GB                               │
│  API endpoint: http://gpu-server:8000/v1    │
├─────────────────────────────────────────────┤
│              CPU-сервер                      │
│  Logera (SvelteKit + FastAPI + PG + MinIO)  │
│  AI-агент (веб + Qdrant + интеграции)       │
│  Whisper (отдельный GPU или CPU fallback)   │
│  32 cores, 256 GB RAM, 4 TB SSD            │
└─────────────────────────────────────────────┘
```

**Преимущества:**
- Один инстанс модели обслуживает оба продукта
- vLLM поддерживает continuous batching → утилизация GPU >80%
- Экономия ~$15-30K на втором GPU-сервере
- Независимое масштабирование CPU и GPU

### Конфигурация совмещённого сервера (всё-в-одном)

| Компонент | Минимум | Рекомендуемая |
|-----------|---------|---------------|
| **GPU** | 2× A100 80GB (LLM + Whisper) | 2× H100 80GB + 1× A6000 (Whisper) |
| **CPU** | 32 cores | 64–96 cores |
| **RAM** | 256 GB DDR5 ECC | 512 GB DDR5 ECC |
| **SSD** | 4 TB NVMe | 2× 4 TB NVMe (RAID 1) + 8 TB storage |
| **Сеть** | 10 Gbit/s | 10 Gbit/s |
| **БП** | 2× 2000W (redundant) | 2× 2400W (redundant) |
| **Ориент. цена** | ~$40-50K | ~$80-120K |

## Минимальные требования к сети и инфраструктуре

| Требование | Значение |
|------------|----------|
| **Канал до сервера** | ≥1 Gbit/s |
| **Внутренняя сеть (если раздельные серверы)** | 10 Gbit/s (NVLink для multi-GPU) |
| **Статический IP** | Да |
| **UPS** | Обязательно (GPU не терпит скачков питания) |
| **Охлаждение** | Серверная с кондиционированием, 20–25°C |
| **Электричество** | 220V/380V, автомат ≥32A на стойку |
| **ОС** | Ubuntu 22.04/24.04 LTS, CUDA 12.x, Docker |

## Рекомендации по оптимизации затрат

1. **Начинать с 4-bit квантизации** — разница в качестве <2% для RAG-задач, экономия VRAM в 4×
2. **Общий LLM-сервер** — один инстанс vLLM на все продукты, continuous batching
3. **Whisper на CPU** — для batch-транскрипции (не real-time) whisper.cpp на CPU достаточно быстр
4. **B/У A100** — надёжные карты, дешевле в 2× новых, гарантия от поставщика
5. **Пилот на облаке** — перед покупкой железа протестировать на cloud GPU (RunPod, Vast.ai)
6. **Sales Coach отдельно** — самый лёгкий продукт, может жить на отдельном сервере за $5-8K
