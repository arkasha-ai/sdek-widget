# Шаблоны документов Gravity Group

Автоматическая генерация документов для Gravity Group в стиле компании.

## 📋 Доступные шаблоны

### 1. ЗАЯВКА к договору (`gravity_zavka_template.py`)

**Что генерирует:**
- Заявка на выполнение работ по рамочному договору
- Таблица сторон (Заказчик/Исполнитель)
- Условия: стоимость, сроки, порядок оплаты, гарантия
- Таблица работ с трудоёмкостью по специалистам
- Таблица подписей

**Пример использования:**

```python
from scripts.gravity_zavka_template import create_zavka_document

data = {
    'zavka_number': '5',
    'contract_number': '14/25',
    'contract_date': '16 мая 2025',
    'zavka_date': '10 марта 2026',
    'cost_total': 200000.00,
    'cost_vat_percent': 5,  # Или None если без НДС
    'work_start': '10 марта 2026',
    'work_end': '30 марта 2026',
    'payment_30_percent': 60000.00,
    'payment_37_percent': 74000.00,
    'warranty_months': 3,
    'customer_name': 'ООО "Инплайн"',
    'customer_inn': '5902054490',
    'customer_director': 'Шевшелев Сергей Викторович',
    'customer_director_short': 'С.В. Шевшелев',
    'works': [
        {
            'category': 'Разработка веб-приложения',
            'items': [
                {'specialist': 'Веб разработчик', 'hours': 40.0},
                {'specialist': 'Дизайнер', 'hours': 16.0},
                {'specialist': 'Специалист по тестированию', 'hours': 12.0}
            ]
        }
    ],
    'appendix': 'Техническое задание'
}

# Генерация документа
doc = create_zavka_document(data)

# Сохранение
doc.save('zavka_5.docx')
```

**Быстрый запуск (пример):**


## 🎨 Стиль и форматирование

Все шаблоны следуют официальному стилю Gravity Group:

- **Шрифт:** Calibri (или системный аналог)
- **Размер:** 11-12pt для основного текста, 14pt для заголовков
- **Таблицы:** границы "Table Grid", выравнивание по контексту
- **Отступы:** первая строка 1.25 см для параграфов
- **Денежные суммы:** автоматическая конвертация в слова (русский язык)

## 📐 Структура данных

### Поля для заявки

| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| `zavka_number` | str | ✅ | Номер заявки (например, "4") |
| `contract_number` | str | ✅ | Номер договора (например, "14/25") |
| `contract_date` | str | ✅ | Дата договора (например, "16 мая 2025") |
| `zavka_date` | str | ✅ | Дата заявки (например, "05 февраля 2026") |
| `cost_total` | float | ✅ | Общая стоимость работ |
| `cost_vat_percent` | int/None | ❌ | Процент НДС (5, 20 или None) |
| `work_start` | str | ✅ | Дата начала работ |
| `work_end` | str | ✅ | Дата окончания работ |
| `payment_30_percent` | float | ✅ | Предоплата 30% |
| `payment_37_percent` | float | ✅ | Вторая часть оплаты 37% |
| `warranty_months` | int | ✅ | Срок гарантии (месяцев) |
| `customer_name` | str | ✅ | Название организации заказчика |
| `customer_inn` | str | ✅ | ИНН заказчика |
| `customer_director` | str | ✅ | ФИО директора заказчика (полное) |
| `customer_director_short` | str | ✅ | ФИО директора заказчика (короткое, например "С.В. Иванов") |
| `works` | list[dict] | ✅ | Список категорий работ и специалистов |
| `appendix` | str | ❌ | Описание приложения (например, "Техническое задание") |

## 💡 Полезные функции

### `number_to_russian_words(num)`

Конвертирует число в слова на русском языке.

```python
number_to_russian_words(147450)
# "сто сорок семь тысяч четыреста пятьдесят"
```

### `money_to_words(amount)`

Конвертирует сумму в слова с копейками.

```python
money_to_words(147450.50)
# "Сто сорок семь тысяч четыреста пятьдесят рублей, 50 копеек"
```

## 📞 Поддержка

При проблемах с генерацией документов проверьте:
1. Все обязательные поля заполнены
2. Типы данных соответствуют ожидаемым
3. Структура `works` корректна
4. Денежные суммы совпадают (30% + 37% ≤ 100%)
