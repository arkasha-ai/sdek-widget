# Fix Hanging Issues

## Проблема
Периодические зависания агента при выполнении команд.

## Причины и решения

### 1. Himalaya IMAP - таймауты
**Проблема:** IMAP может зависнуть если сервер не отвечает.

**Решение:**
```bash
# Всегда использовать timeout для himalaya команд
timeout 30s himalaya envelope list
# Или через exec с yieldMs
```

### 2. Browser операции
**Проблема:** Browser может упасть, повторные попытки зависают.

**Решение:**
- Перед каждой browser операцией проверять статус
- Использовать browser.status перед действиями
- Не пытаться использовать мёртвую вкладку

### 3. Long-running exec
**Проблема:** Exec команды без yieldMs блокируют выполнение.

**Решение:**
```javascript
// ВСЕГДА использовать yieldMs для потенциально долгих команд
exec("himalaya ...", { yieldMs: 10000 })
exec("curl ...", { yieldMs: 5000 })
exec("python3 ...", { yieldMs: 30000 })
```

### 4. Qdrant indexer
**Проблема:** Индексация 40+ писем может занять время.

**Решение:**
- Запускать через background exec
- Использовать process.poll для проверки статуса
- Не ждать синхронно

## Правила для себя
1. **ВСЕГДА yieldMs для**: himalaya, curl, python3, длинных операций
2. **Проверять browser.status** перед использованием
3. **timeout** для внешних сервисов (IMAP, SMTP, HTTP)
4. **background + poll** для долгих задач (индексация, обработка)

## Мониторинг
Добавить в heartbeat проверку зависших процессов:
```bash
ps aux | grep -E "himalaya|python3.*qdrant" | grep -v grep
```
