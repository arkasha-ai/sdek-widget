**Используемые стили:**
- Normal
- Normal Table
- Body Text
- Compact
- First Paragraph

**Основные:**

## 📝 ПАРАГРАФЫ

### Заголовки заявок (ЗАЯВКА №X)

```python
{
    'style': 'Normal',
    'left_indent': '28.35pt',      # ⚠️ ВАЖНО!
    'first_line_indent': '-28.35pt',  # ⚠️ Висячая строка
    'space_before': '6.00pt',
    'space_after': '6.00pt',
    'line_spacing': '1.2',
    'font': {
        'name': 'Calibri',         # ⚠️ НЕ Arial!
        'size': '12.0pt',
        'bold': True,
        'color': '000000'
    }
}
```

### Обычный текст

```python
{
    'style': 'Normal',
    'space_before': '6.00pt',
    'space_after': '6.00pt',
    'line_spacing': '1.2',
    'font': {
        'name': 'Calibri',
        'size': '12.0pt',
        'color': '000000'
    }
}
```

### Текст с отступами (списочный)

```python
{
    'style': 'Normal',
    'left_indent': '28.35pt',      # Для списков
    'first_line_indent': '-28.35pt',  # Висячая строка
    'space_before': '6.00pt',
    'space_after': '6.00pt',
    'line_spacing': '1.2'
}
```

**⚠️ КРИТИЧНО:**
- `left_indent: 28.35pt` + `first_line_indent: -28.35pt` = висячая строка (hanging indent)
- Это НЕ zero indent! Первая строка на 28.35pt левее остальных

**Структура:**
- 2 строки x 2 колонки
- Стиль: `Normal Table`
- Ширина колонок:
  - Колонка 1: 4.25см (заголовки)

**Границы:**

- Параграф:

  - `line_spacing`: 1.2
  - `style`: Normal
- Шрифт заголовков:
  - Calibri, 12pt, Bold, Black

**Границы:**

**Ячейки заголовка:**

  - `style`: Normal

- Ячейки:
  - Стиль параграфа: `Compact`
  - Граница снизу первой строки: `none` (объединённые ячейки?)
