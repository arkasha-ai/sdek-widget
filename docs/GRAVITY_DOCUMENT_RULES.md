## 📐 РАЗМЕРЫ СТРАНИЦЫ И MARGINS

```python
section.top_margin = Cm(2.0)
section.bottom_margin = Cm(2.0)
section.left_margin = Cm(3.0)    # ⚠️ НЕ 2см!
section.right_margin = Cm(1.5)   # ⚠️ НЕ 2см!
```

**Почему важно:**
- Left 3см (не стандартные 2см) - для подшивки документов
- Right 1.5см - экономия места
- Если установить стандартные 2см, текст будет смещён

## 🔤 ШРИФТЫ

**Основной шрифт:**
```python
run.font.name = 'Calibri'  # ⚠️ НЕ Arial!
run.font.size = Pt(12)     # Везде 12pt
run.font.color.rgb = RGBColor(0, 0, 0)  # Чёрный
```

**Почему Calibri, а не Arial:**
- Calibri имеет другую метрику символов
- Влияет на переносы строк и общий размер документа
- В оригинале используется именно Calibri

**Когда применять Bold:**
- Заголовки (ЗАЯВКА №X, Дата Заявки)
- Названия колонок в таблицах
- Категории работ в таблице работ
- Заголовки "ЗАКАЗЧИК" / "ИСПОЛНИТЕЛЬ"

## 📝 ПАРАГРАФЫ - Висячие Строки (Hanging Indent)

**Критичная деталь!** Большинство параграфов имеют висячую строку:

```python
para.paragraph_format.left_indent = Pt(28.35)
para.paragraph_format.first_line_indent = Pt(-28.35)
```

**Что это значит:**
- Первая строка начинается на 28.35pt **левее** остальных
- Это НЕ нулевой отступ!
- Визуально создаёт эффект списка без маркера

**Где применяется:**
- Заголовки (ЗАЯВКА №X, Дата Заявки)
- Параграфы с отступами (большинство текста в заявке)

**Где НЕ применяется:**
- Короткие параграфы без отступов (например, "согласовали следующий условия...")

---

## 📏 ИНТЕРВАЛЫ

**Стандартные значения:**
```python
para.paragraph_format.space_before = Pt(6)
para.paragraph_format.space_after = Pt(6)
para.paragraph_format.line_spacing = 1.2  # Межстрочный интервал
```

**Применяется:** Во ВСЕХ параграфах и ячейках таблиц

**Почему важно:**
- space_before/after 6pt создаёт визуальную воздушность
- line_spacing 1.2 (не 1.0!) делает текст читабельнее
- Если забыть, документ будет выглядеть плотнее оригинала

## 📊 ТАБЛИЦЫ - Общие Правила

**Стиль:**
```python
table.style = 'Normal Table'  # ⚠️ НЕ 'Table Grid'!
```

**Цвет границ:**
```python
color_hex = '5F497A'  # Фиолетовый (RGB: 95, 73, 122)
sz = '4'              # Толщина
```

**Ширины колонок - ТОЧНЫЕ значения!**
- Таблица сторон: 4.25см x 12.26см
- Таблица работ: 1.25см x 11.00см x 3.86см
- Таблица подписей: 8.24см x 8.24см

**Почему точные:**
- Влияет на переносы строк внутри ячеек
- Если колонка уже, текст может перенестись неправильно

## 🎓 УРОКИ

**1. Каждая деталь важна**
- Нельзя пропускать "мелочи" (margins, отступы, интервалы)
- Они все влияют на итоговый вид

**2. Анализ оригинала - must have**
- Без детального анализа оригинала не получится точную копию
- Нужно проверять каждый параграф, каждую ячейку

**3. Висячие строки (hanging indent) - не очевидны**
- Выглядят как простые отступы, но это не так
- left_indent + first_line_indent создают уникальный эффект

**4. Ширины колонок критичны**
- Влияют на переносы строк
- Если колонка уже, текст может не влезть

**5. Calibri vs Arial - это важно**
- Разная метрика символов
- Влияет на общий размер документа
