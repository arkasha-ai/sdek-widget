### 2. SOUL Evil Hook
- **Docs:** https://docs.openclaw.ai/hooks/soul-evil
- Swaps SOUL.md with SOUL_EVIL.md temporarily (in memory, not on disk)
- Config: purge window (e.g. 21:00-21:15) + random chance (0-1)
- Use cases: experiments, fun mode, testing alternate personalities
- **Decision:** Interesting for experiments, not for production

### 3. Voice Wake (Global Wake Words)
- **Docs:** https://docs.openclaw.ai/nodes/voicewake
- Wake words for voice activation (like "Hey Siri")
- Default: `["openclaw", "claude", "computer"]`
- Global list managed by Gateway, synced across devices
- Storage: `~/.openclaw/settings/voicewake.json`
- Supported: macOS app, iOS node, Android node
- **Decision:** Cool feature, but requires iOS/Android node

## TTS (Text-to-Speech) Setup

### Initial Investigation
- Checked if LiteLLM supports TTS: ❌ No (only Whisper for transcription)
- Explored options: OpenAI TTS, ElevenLabs, Edge TTS

### Solution: Edge TTS (Free!)
- **Provider:** Microsoft Edge TTS (via `node-edge-tts`)
- ✅ Completely free, no API key needed
- ✅ Good quality (Neural TTS)
- ✅ Russian language support
- ✅ Already built into OpenClaw

### Configuration Applied
```json
{
  "messages": {
    "tts": {
      "auto": "off",  // Only when explicitly requested
      "provider": "edge",
      "edge": {
        "voice": "ru-RU-DmitryNeural"
      }
    }
  }
}
```

**Settings:**
- `auto: off` - голосовые по умолчанию выключены
- `provider: edge` - Edge TTS (бесплатный)
- `voice: ru-RU-DmitryNeural` - мужской русский голос

**Agreement with Denis:**
