**Ошибка:** "unauthorized: device token mismatch (rotate/reissue device token)"
**Что я наделал (всё неправильно):**
1. Ротировал токен через `openclaw devices rotate` ✅
2. Записал токен в НЕПРАВИЛЬНЫЙ файл `node-device-token.txt` ❌ (должен быть в `node.json` поле `token`)
3. Revoke сделал ❌ (усложнил ситуацию)
4. Повторно ротировал, записал в node.json — всё равно не работает
5. Удалил identity/device.json + node.json для чистого старта — всё равно не работает

**Что я узнал из исходников:**
- Device identity: `~/.openclaw/identity/device.json` (ed25519 keypair → deviceId)
- Node config: `~/.openclaw/node.json` (nodeId, displayName, gateway, **token**)
- DeviceId = sha256 fingerprint от publicKey
- `openclaw devices` CLI: list, approve, reject, rotate, revoke (нет delete!)

**Документация:**
- https://docs.openclaw.ai/cli/devices — управление device tokens
- https://docs.openclaw.ai/nodes/index — полная документация по nodes

**Вероятная причина:** Несовместимость версий (beast v2026.2.9, Gateway v2026.2.17). Предложил обновить OpenClaw на beast.
