## 23:00 - ФУНДАМЕНТАЛЬНАЯ ОШИБКА НАЙДЕНА: Document() с нуля ≠ оригинал

**Проблема Дениса:** "Мимо на 70% всего документа"

**Корневая причина:**
`Document()` (python-docx) создаёт документ с ДЕФОЛТНЫМ шаблоном, который имеет:
- 164 стиля (вместо 27 у Gravity Group)
- Тему: majorFont=Calibri, minorFont=Cambria (вместо Calibri Light / Calibri)
- Стиль Normal: без настроек (вместо Times New Roman 13pt)
- Другие docDefaults, header/footer distances

**Даже если я вручную задаю каждый run → пустые параграфы, ячейки без run'ов и стили таблиц НАСЛЕДУЮТ дефолтные настройки python-docx.**

**Решение:** Использовать оригинал как шаблон!
```python
doc = Document('/path/to/original.docx')  # Открыть оригинал
# Очистить body (сохранив sectPr)
# Deep copy элементы
```

Это сохраняет:
- ✅ Все 27 кастомных стилей Gravity Group
- ✅ Тему (Calibri Light / Calibri)  
- ✅ docDefaults
- ✅ Header/footer distances
- ✅ Кастомный Normal стиль

**УРОК #1 (КРИТИЧНЫЙ):** НИКОГДА не создавать `Document()` с нуля для воспроизведения существующих документов! Всегда использовать оригинал как шаблон.
