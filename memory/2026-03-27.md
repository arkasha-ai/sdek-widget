## Архитектура video understanding (обсуждали утром)

**Идея: два эмбеддера для разных задач**

- **Semantic search** (что происходит на сцене) → CLIP / Qwen3-VL-Embedding
- **Face search** (найти конкретного человека) → InsightFace / ArcFace

VL-эмбеддинг кодирует внешние признаки, но не биометрическую идентичность.
Face recognition обучен через triplet loss/ArcFace — один человек = стабильный вектор независимо от угла и освещения.

**Пайплайн:**
```
видео → кадры
  ├── CLIP/VL → семантический индекс (Qdrant) → поиск по сцене
  └── InsightFace → face index (Qdrant) → поиск по конкретному человеку
```

Оба индекса в Qdrant, запрос выбирает нужный в зависимости от задачи.

## КРИТИЧЕСКИЕ ПРАВИЛА (от Миши, 27.03.2026)

### 1. Google API — ТОЛЬКО через SOCKS5 прокси
**НИКОГДА** не обращаться к Google API (Gemini, AI Studio) напрямую по IP без VPN/прокси.
Причина: нас заблокируют и потеряем доступ + влетим на деньги.
Прокси: `GOOGLE_SOCKS5_PROXY` из secrets.env (задан в Dokploy env на сервере).
Если здесь пустой — значит не тестировать локально, только через деплой.

### 2. fal.ai — не используем
Полный отстой. Забыть про него. Не предлагать, не использовать.
Единственный image provider: **Gemini** (через прокси).
