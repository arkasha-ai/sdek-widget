### SyncVoice — Qwen3-ASR для STT
Обсуждали в чате "Denis, Аркаша и Бульченок" (-5136324785):
- Идея: база аудио-записей терминов (препараты, хим. соединения) → кормить как few-shot в STT
- Qwen2-Audio поддерживает multiple audio inputs в conversation, но ход 30с паддинг → 100 терминов не влезет
- **Qwen3-ASR** — лучший вариант:
  - Собственная архитектура (не Whisper внутри), dynamic window 1-8 сек
  - 52 языка: русский, английский, хинди, китайский — все нужные для SyncVoice
  - Поддерживает text context prompt для hotwords/терминов
  - 0.6B / 1.7B — лёгкие, быстрые
  - Streaming, vLLM, on-premise, open-source
  - `--prompt "Метформин, левотироксин, ..."` — список терминов прямо в промпт
- Для 100+ терминов: текстовый глоссарий, не аудио-база
- Аудио-база терминов полезна для fine-tuning или как TTS-озвучка глоссария
