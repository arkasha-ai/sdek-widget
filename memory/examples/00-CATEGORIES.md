# Few-Shot Examples — Categories

Это референс для улучшения качества ответов MiniMax-M2.7.
Перед сложной задачей — читай соответствующий файл.

| Файл | Тип задач |
|------|-----------|
| `01-code-debug.md` | Код, отладка, рефакторинг |
| `02-documents.md` | Документы, заявки, отчёты, шаблоны |
| `03-api-debug.md` | API интеграции, вебхуки, сети |
| `04-content-text.md` | Тексты, посты, описания |
| `05-research.md` | Исследование, поиск, анализ |

**Как использовать:** Если задача подходит под категорию — возьми паттерн из примера и адаптируй.
