# Few-Shot: Тексты и контент

## Паттерн: VK пост для кафе

**Структура поста:**
1. Зацепка — вопрос или провокация (1 предложение)
2. Основной текст — 2-3 абзаца, история
3. Призыв к действию — "приходите", "бронируйте"
4. Контакты — телефон, адрес, время работы

**Требования:**
- Тёплый, дружеский тон
- Без официоза
- 1-3 эмодзи максимум
- Списки через тире (—)
- Проверка: нет случайных иероглифов

**Пример (вход → выход):**

Запрос: "Напиши пост про полуфабрикаты для кафе"

Выход:
```
🍽️ А вы знали, что наши котлеты делают вручную каждое утро?

Рассказываем, почему именно так:

— Мясо от локального фермера, не заморозка
— Никакого льда и воды в фарше
— Каждая котлета — ручная лепка

Попробуйте разницу. Ждём вас!
```

**Антипаттерн:** не вставлять конкретные адреса/телефоны клиента в примеры.

## Паттерн: Сторис для соцсетей

**Формат:**
- 3-4 кадра
- Каждый кадр — одна мысль
- Последний кадр — призыв или контакты

**Пример сторис:**
```
Кадр 1: "Скоро сезон цветения"
Кадр 2: "Важно знать:"
        — Три волны: апрель-май, июнь-июль, август-сентябрь
        — Симптомы легко спутать с простудой
        — Аллергия может появиться внезапно
Кадр 3: Как именно — в видео с аллергологом ⬇️
```

## Паттерн: Отписка от рассылки

Если просят отписать от Cloud.ru или другой рассылки:
```
Перейти по ссылке в письме (обычно внизу "Unsubscribe")
Или: написать reply с текстом "Unsubscribe"
Или: пометить письмо как спам (если другого выхода нет)
```

**Никогда не отправлять "отписать" в ответ на маркетинговое письмо** — это подтверждает email и может увеличить спам.
