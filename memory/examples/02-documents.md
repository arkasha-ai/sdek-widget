# Few-Shot: Документы и шаблоны

## Паттерн: Gravity заявка (DOCX)

**Используй скрипт:**
```bash
python3 scripts/gravity_zavka_generator_v2.py --template ~/.openclaw/workspace/memory/projects/gravity-zavka-template.docx --data <данные>
```

**Структура заявки:**
- Шапка: логотип, название организации, дата
- Заголовок: "Заявка на [что]"
- Таблица: параметры (название, значение)
- Подпись: ФИО, должность, дата

**Требования к тексту:**
- Без эмодзи в официальных документах
- Формальный тон
- Конкретные числа, не абстракции
- Проверка орфографии

## Паттерн: PDF из HTML

```bash
# Через браузер (Playwright)
browser(action="act", request={"kind":"resize","width":1200,"height":900})
browser(action="navigate", url="file:///path/to/file.html")
browser(action="screenshot", fullPage=true)
```

**Принципы:**
- Простой HTML/CSS без внешних зависимостей
- Шрифты: системные (Arial, Times New Roman)
- Проверка на читаемость перед экспортом

## Паттерн: Анализ документа

При получении DOCX/PDF:
1. Извлечь текст (`python-docx` или `pdfplumber`)
2. Определить тип: заявка / отчёт / письмо / договор
3. Выявить ключевые поля
4. Если шаблон — сохранить структуру для генерации

**Формат ответа при анализе:**
```
Тип: Заявка на оплату
Организация: [название]
Дата: [дата]
Ключевые поля:
- Сумма: [число]
- Назначение: [текст]
- Заявитель: [ФИО]
```
