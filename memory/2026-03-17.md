**Критические правила для PDF через браузер:**
1. НЕ использовать emoji — рендерятся как квадраты
2. НЕ использовать CSS grid — не работает в PDF, использовать HTML `<table>`
3. НЕ писать `<-- комментарий -->` — рендерятся как текст; только `<!-- -->` или убрать
4. Буллеты: только `-` (тире) — всё остальное = квадраты
5. HTML-таблицы для колонок — единственный надёжный способ

**Workflow PDF:**
- HTML → локальный HTTP сервер (port 9876/9877) → browser.pdf → fitz → JPEG

**Workflow JPEG из PDF:**
```python
import fitz
pix = page.get_pixmap(matrix=fitz.Matrix(2.5, 2.5))
pix.save(path, jpg_quality=92)
```
