## Docker диск на Windows (i9-4090-beast)

### Проблема
- C: занято 851GB из 931GB (81GB осталось)
- Причина: `C:\Users\topit\AppData\Local\Docker\wsl\disk\docker_data.vhdx` = **355GB**
- WSL2 диск Docker раздулся, не сжимается автоматически

### Диагностика
```
docker system df показал:
- Images: 0 (пусто)
- Containers: 0 (пусто)
- Volumes: 26, 8.6GB (все неактивные)
- Build Cache: 0
```
Реальных данных минимум, но vhdx файл огромный.

### Решение (объяснено Денису)
1. `docker volume prune` — удалить 8.6GB volumes
2. Сжать vhdx через diskpart (от админа):
```
diskpart
select vdisk file="C:\Users\topit\AppData\Local\Docker\wsl\disk\docker_data.vhdx"
attach vdisk readonly
compact vdisk
detach vdisk
exit
```
Ожидаемый результат: вернуть ~300GB

### Прочее найденное
- `.lmstudio`: 21GB (модели LM Studio)
- Temp: 14GB
- ProgramData: 13GB
- ComfyUI (`C:\work\ComfyUI`): всего 104MB
