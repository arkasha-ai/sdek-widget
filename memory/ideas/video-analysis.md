# Идея: Анализ видео встреч через кадры

**Дата:** 2026-03-04
**Статус:** 💡 Идея

## Суть
Использовать Logera recordings для автоматического конспектирования встреч:
1. Видео из Logera/MinIO
2. ffmpeg scene detection → только уникальные кадры (не каждые N сек)
3. Image analysis → краткое описание каждого кадра (1 предложение)
4. Совместить с транскриптом + diarization из Logera ASR
5. Итог: конспект с таймкодами, говорящими и скриншотами экрана

## Технические детали
```bash
# Только кадры где экран изменился на 30%+
ffmpeg -i video.mp4 -vf "select='gt(scene,0.3)'" -vsync vfr frames/%04d.jpg
```
- Часовой митинг → ~20-50 уникальных кадров вместо 700
- ~200-300 токенов на кадр → приемлемо

## Что нужно
- Доступ к Logera API / MinIO для получения видео
- Тестовая запись встречи

## Связь
- Logera workers: `media_prep`, `diarization`, `asr` уже делают часть пайплайна
- Можно добавить как отдельный воркер или запускать вручную
