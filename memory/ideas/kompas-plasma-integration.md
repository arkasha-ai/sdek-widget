# Идея: Интеграция КОМПАС 3D + Плазморез

**Дата:** 2026-03-04
**Статус:** ✅ Исследовано — реализуемо
**Контакт:** Александр Воробьев (@aleksandrjust)

## Суть
Автоматизация производства на заводе крёстного Саши в Пензе:
- Делают станки, режут металл плазмой
- Сейчас: ручная работа в КОМПАС 3D + программа раскроя
- Цель: фото чертежа → автоматический раскрой → NC-программа для станка

## Целевой пайплайн
1. Фото письменного чертежа → распознать геометрию + размеры (image AI)
2. Сгенерировать DXF через `ezdxf` Python библиотеку
3. Через КОМПАС MCP-сервер (COM API) → создать/проверить чертёж на Windows ноде
4. Передать DXF в программу раскроя с параметрами (материал, размер листа, кол-во деталей)
5. Получить NC-программу
6. Оператор подтверждает → запуск резки

## Исследование по блокам

### 1. КОМПАС 3D API ✅
**Работает через Python + COM API (только Windows)**
- Уже есть готовый MCP-сервер — мост между LLM и КОМПАС (статья январь 2026)
- Умеет: создавать геометрию (линии, дуги, окружности, прямоугольники), редактировать, экспортировать DXF/JSON
- Есть `execute_python_script` — выполнение произвольного кода прямо в контексте КОМПАС
- Денис даёт Windows ноду → подключаемся и работаем
- 🔗 https://habr.com/ru/articles/987312/ — MCP КОМПАС-3D + LLM (Python, COM API)
- 🔗 https://habr.com/ru/company/ascon/blog/328088/ — Урок 1: основы API КОМПАС-3D
- 🔗 https://vk.com/python_macros — сообщество Python + КОМПАС-3D

### 2. Фото → DXF ✅
**Реализуемо, есть готовые решения**
- `Image2CAD` — open source, OpenCV + ML, конвертирует растр чертежа в DXF
- `Scan2CAD` — коммерческий, быстрый, хорошее качество
- Альтернатива: image-анализ (распознать размеры) → генерация DXF через `ezdxf`
- Слабое место: рукописные чертежи с плохим освещением — нужны уточняющие вопросы перед генерацией
- 🔗 https://github.com/adityaintwala/Image2CAD — open source image → DXF
- 🔗 https://www.scan2cad.com/blog/dxf/convert/image-to-dxf/ — туториал Scan2CAD
- 🔗 https://hyper3d.ai/tools/image-to-dxf — онлайн конвертер

### 3. Раскрой / Nesting ✅
**Есть open source варианты с CLI**
- **Deepnest** — open source, для плазморезов и лазеров, принимает DXF/SVG
- **SVGNest** — open source, автоматический nesting
- **FastCAM** — коммерческий CAD/CAM для плазмы, полный цикл
- **Lantek Expert Cut** — коммерческий, самый продвинутый API
- Ждём от Саши название их текущей программы → возможно уже есть API/CLI
- 🔗 https://deepnest.io/ — open source nesting для плазмы
- 🔗 https://svgnest.com/ — free open source nesting
- 🔗 https://www.fastcam.com/fastcam-nc-nesting-system.html — FastCAM plasma
- 🔗 https://www.lantek.com/us/cad-cam-nesting-software-oxycut-plasma-laser-waterjet — Lantek
