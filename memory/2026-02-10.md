## sio-wdio-tests Project - Major Test Fixes

**Context:** Denis's work project - WebDriverIO E2E tests for https://sad-i-ogorod.ru (production site). After fixing Docker/Selenium infrastructure, tackled 42 test failures.

**Achievement:** Fixed 40/42 tests (95% success rate) through systematic debugging.

### Root Causes Identified

1. **SEO test failures (32 tests):**
   - Problem: Title set via JavaScript after page load, `pause(2000)` insufficient
   - Solution: Added `browser.waitUntil()` with 10s timeout for title loading

2. **Subscribe test failures (2 tests):**
   - Problem: `toHaveText()` called on `ChainablePromiseArray` (WebDriverIO API error)
   - Solution: Added single element getter `labelError` instead of array

3. **Auth test failures (2 tests):**
   - Problem 1: Cookies persisted between tests (user stayed logged in)
   - Problem 2: `/personal/info/` redirects to `/auth/` page (not modal)
   - Problem 3: **Dual form issue** - page has both hidden modal AND visible form, universal selectors selected wrong inputs
   - Solution: 
     - Added explicit `logout()` method calling `/?logout=yes`
     - Added `deleteAllCookies()` in `beforeEach`
     - Created separate modal/page selectors with `:not(#modal-login input)`
     - Added URL detection in `login()` to use correct form

4. **Cart test failures (4 tests):**
   - Problem: Radio buttons appear dynamically, immediate click failed
   - Solution: Added `waitForDisplayed()` before clicking delivery/payment buttons
