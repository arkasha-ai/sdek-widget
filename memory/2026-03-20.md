## Утро — Znaem AI группа (znaem-landing фиксы)

### Анимации — `whileInView` фикс
Исправлены анимации на 4 секциях:

**Cases.tsx** — карточки были невидимы на десктопе из-за `whileInView` внутри горизонтального скролл-контейнера.
- Обёрнули каждую карточку в `motion.div` с `viewport={{ once: true, root: scrollRef }}`
- Stagger: `delay: i * 0.1`, `ease: [0.25, 0.46, 0.45, 0.94]`
- `initial: { opacity: 0, y: 40 }`

**Services.tsx, Team.tsx, Contact.tsx** — везде была одна проблема:
- `animate` вместо `whileInView` → анимации срабатывали при загрузке, не при скролле
- `y: 0` в initial → никакого движения
- Исправлено: `whileInView`, `viewport={{ once: true }}`, `initial: { opacity: 0, y: 30/40 }`
