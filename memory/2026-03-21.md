## Сессия ~17:00-18:39 - WB карточки товаров (группа Znaem AI, Михаил Корзов)

### Контекст
Работа в группе `Znaem AI` (-1003831241406) с Михаилом Корзовым (@mskorzhov, 1304250058) и Денисом. Разрабатываем пайплайн для генерации маркетинговых карточек товаров для Wildberries.

### Итоговый рабочий пайплайн (одобрен Денисом)
1. Берём исходное фото товара
2. **bria/generate-background** на Replicate → убирает фон, генерирует тематическую сцену
3. Смотрим через `image()` tool: где встал товар, сколько места слева
4. HTML/CSS поверх: контент `position:absolute`, ширина строго до левого края товара - 40px запас
5. Текстовый блок — **frosted glass** плашка (`backdrop-filter:blur(12px)`, `rgba(255,248,235,0.45)`)
6. Вертикальное центрирование: `margin-top:auto; margin-bottom:auto`
7. Playwright → JPEG 95

### Ключевые правила вёрстки
- Фон через `<img>` тег absolute (НЕ background-image на body — body будет белым)
- НЕ использовать gradient overlay на всю половину — перекрывает фон
- body и .content — `background: transparent` явно
- Frosted glass только под текстовым блоком (не на весь контент)

### bria/generate-background — поведение
- Хорошо убирает фон и создаёт сцену
- **Игнорирует позиционирование в промпте** — всегда центрирует товар
- Для детских игрушек оставляет ~50% слева чистыми (бокe)
- Для одежды/курток — центрирует на всю ширину → адаптируем текст вниз/вверх
