## 12:41 — Gravity LLM: Анализ CSS vs JS виджета СДЭК

**Участники:** Ярослав Владимирович (lar_dragon, 608677348), Andrew (yandrw)

**Суть:** Ярослав просил найти в коде работу с VueYandexMaps. Сначала скинул CSS-файл виджета, затем попросил игнорировать CSS и читать только JavaScript.

**Важно:** Оба файла (widget---9c32aa14... и widget---da9f81d4...) — это **CSS-бандлы**, упакованные в JavaScript-обёртку для динамической инъекции через `document.createElement("style")`. Никакой логики JS в них нет.

Стили определяются по паттерну:
- `@font-face` шрифты (Fira Code, Fira Mono, Roboto)
- CSS-переменные `--un-*` (Tailwind UnoCSS)
- Компонентные классы с префиксом `cdek-*` (СДЭК)
- Vue-scoped атрибуты `data-v-[hash]`
- CSS-анимации `spin-*`

**Вывод:** Для анализа API-запросов к Яндекс.Картам нужны Network-логи или исходные `.js`/`.vue` файлы, а не CSS-бандлы.
