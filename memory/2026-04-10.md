## SdekPvzWidget — фиксы и модернизация

**Проект:** `/tmp/sdek-widget/sdek-widget/`
**GitHub:** `https://github.com/arkasha-ai/sdek-widget`

### Что сделано

1. **MapPane.vue** — мигрирован с deprecated `ol-style-circle`/`ol-stroke`/`ol-fill` (удалены в vue3-openlayers v11+) на нативные OL Style objects (`Style`, `Circle`, `Stroke`, `Fill`)

2. **SdekPvzWidget.js** — заменён inline `template:` string на `render()` с `h()` (убрал зависимость от Vue runtime compiler)

3. **vue3-openlayers tree-shaking fix** — добавлены явные импорты чтобы Rollup не выкидывал компоненты из бандла:
   ```js
   import 'vue3-openlayers/map';
   import 'vue3-openlayers/layers';
   import 'vue3-openlayers/sources';
   import 'vue3-openlayers/geometries';
   ```

4. **vite.config.js** — фикс output filename (убрал `entryFileNames: '[name].js'` который вызывал коллизию ES/UMD); формат только UMD, `inlineDynamicImports: true`

5. **index-dist.html** — создан для тестирования production build

6. **Dockerfile + docker-compose.yml** — для запуска тестового стенда (Vite dev + PHP backend)

7. **.gitignore** — добавлен, node_modules удалён через `filter-branch`

8. **MapPane.vue getView() fix** — `ol-map` компонент НЕ экспоунит `getView()`. OL-карта доступна через `inject('map')`. Все методы `panTo`, `getBounds`, `updateSize` теперь используют `olMap` из inject.
