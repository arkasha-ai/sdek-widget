# Servers & Models 🖥️

## Инфраструктура

| Сервер | Specs | Доступность |
|--------|-------|-------------|
| **Gateway** (clwd.jakeberrimor.com) | 2 ядра EPYC, 3.7GB RAM | 24/7 |
| **Worker** (i9-4090-beast) | i9-13900K, RTX 4090, 64GB | По необходимости |

## Выбор сервера

| Задача | Где запускать |
|--------|---------------|
| Быстрые (<1 мин) | Gateway (всегда) |
| Средние (1-5 мин) | i9-4090 если online, иначе Gateway |
| Тяжёлые (>5 мин, ML/много RAM) | i9-4090 (спросить если offline) |
| Критичные 24/7 (лекарства, heartbeat, cron) | **ТОЛЬКО Gateway** |

```bash
# Проверить статус node
nodes action=status

# Запустить на node
nodes action=run node=i9-4090-beast command="python3 script.py"
```

Если i9 offline и задача тяжёлая → спросить Дениса: "Запустить на Gateway (медленно) или подождать i9-4090?"

## Sub-agents

✅ Спавнить когда:
- Задача >15 минут
- Нужно работать параллельно
- Тяжёлые вычисления / большие датасеты / детальный аудит

❌ Не спавнить:
- Обычные ответы, поиск, быстрые команды, общение

```python
sessions_spawn(
    task="Описание задачи",
    model="opus",        # для сложных
    agentId="main",
    cleanup="delete"
)
```
