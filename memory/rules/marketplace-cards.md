# База знаний: Карточки товаров WB и Ozon
> Практическое руководство для AI-агента по автоматизации карточек маркетплейсов.
> Версия: 1.0 | Обновлено: 2026-03-21

---

## 1. Технические требования

### Wildberries

| Параметр | Значение |
|----------|----------|
| Форматы | JPG, PNG, WEBP |
| Соотношение сторон | 3:4 (вертикальная ориентация) |
| Минимальное разрешение | 700×900 px |
| Рекомендуемое разрешение | 1000×1000 px (квадрат тоже принимается) |
| Максимум по стороне | 8000 px |
| Размер файла | Не более 10 МБ |
| Цветовая модель | RGB (CMYK — запрещено!) |
| Фон главного фото | Белый или прозрачный |
| Мин. площадь товара | 20% для одежды / 10% для обуви и аксессуаров |

### Ozon

| Параметр | Значение |
|----------|----------|
| Форматы | JPG, PNG |
| Соотношение сторон | 1:1 (квадрат, рекомендуется) или 3:4 |
| Минимальное разрешение | 200×200 px |
| Рекомендуемое разрешение | 1000×1000 px и выше |
| Максимальное разрешение | 10000×10000 px |
| Размер файла | Не более 10 МБ |
| Цветовая модель | RGB |
| Фон главного фото | Белый (#FFFFFF) рекомендуется |
| Количество фото | До 15 штук |

> **⚠️ Ключевые различия WB vs Ozon:**
> - WB требует строго 3:4, Ozon предпочитает 1:1
> - Ozon допускает цветной фон на главном фото (если нет специальных требований категории)
> - На Ozon важна rich-content секция — можно добавлять видео и 360°

## 2. Структура карточки

### Типы фото и их задачи

#### 📸 Фото 1 — Главное (Hero Shot)
**Задача:** Зацепить взгляд, передать суть товара, выделиться в каталоге.

**Что должно быть:**
- Товар на белом/прозрачном фоне
- Товар крупно, занимает 60-80% кадра
- 3-5 ключевых преимущества в виде коротких подписей/иконок
- Название / бренд (по необходимости)
- Цветовая схема — чистая, не перегружена

**Что НЕ должно быть:**
- Цены, скидки, % выгоды
- Слова: Лучший, Топовый, №1, Хит, Супер
- Логотипы WB, Ozon, конкурентов
- Перекрывающие товар элементы
- Водяные знаки

---

#### 📊 Фото 2-3 — Инфографика
**Задача:** Дать покупателю всё нужное для решения о покупке без чтения описания.

**Структура инфографики:**
1. **Название / бренд** — крупно, в верхней зоне
2. **3-5 ключевых характеристик** — иконка + краткое описание
3. **Сферы применения** — для кого / когда / зачем
4. **Ответы на частые вопросы** — предвосхитить возражения
5. **Преимущества предложения** — гарантия, сертификаты, упаковка, доставка

**Принципы:**
- Текст читабелен без зума (шрифт ≥ 16px)
- Максимум 2 разных шрифта
- Цветов — оптимально 3-4
- Фон контрастирует с текстом

---

#### 🔍 Фото 4-5 — Детали
**Задача:** Показать качество, материал, фурнитуру, швы, текстуру, технологии.

**Что снимать:**
- Материал крупным планом
- Элементы конструкции (замки, кнопки, молнии, швы)
- Брендирование (лейблы, гравировки)
- Уникальные технологические особенности

---

#### 📦 Фото 6 — Комплектация
**Задача:** Показать что входит в коробку, устранить возражение "а что там внутри?".

**Содержимое:**
- Все предметы комплекта разложены и подписаны
- Упаковка (если является плюсом)
- Документы / гарантийный талон (если есть)

---

#### 🏠 Фото 7-8 — Lifestyle (в использовании)
**Задача:** Помочь покупателю представить товар в своей жизни.

**Принципы:**
- Реальный или реалистичный контекст использования
- Модель (если применимо) должна соответствовать ЦА
- Эмоция и настроение, а не просто демонстрация

---

#### 📐 Фото 9 — Размерная сетка / Габариты
**Задача:** Снять страх "не подойдёт по размеру".

**Что включать:**
- Таблица размеров (рост/вес для одежды, длина/ширина для предметов)
- Схема замеров с указанием точек измерения
- Сравнение с привычным предметом (линейка, монета)

## 3. Правила дизайна

### Шрифты
- Минимальный размер: **16px** (меньше — не читается в мобильном каталоге)
- Максимум разных шрифтов: **2** (один для заголовков, один для текста)
- Рекомендуемые семейства: гротески (sans-serif) — читабельнее на экране
- Жирное начертание для заголовков — лучше воспринимается при скролле

### Цвета
- Оптимальная палитра: **3-4 цвета**
- Цветовая модель: только **RGB** (HEX для дизайна)
- Фон главного фото: `#FFFFFF` (белый) или прозрачный
- Акцентный цвет должен быть 1 — не больше
- Проверяй контраст: соотношение контраста текст/фон ≥ 4.5:1

### Свободные зоны (WB) — не перекрывать!

```
┌──[NEW]─────────────[♥]──┐
│                          │
│       ТОВАР              │
│                          │
│                          │
│──[ПРОМО]──[СКИДКА]───────│
└──────────────────────────┘
```

| Зона | Где | Что там отображает WB |
|------|-----|-----------------------|
| Левый верхний угол | ~15% ширины, ~8% высоты | Значок "New" / "Хит" |
| Правый верхний угол | ~10% ширины, ~8% высоты | Кнопка "Избранное" (сердечко) |
| Нижняя полоса | 100% ширины, ~12% высоты | Плашки промотовар / распродажа |

**Правило:** Не размещай важные элементы в этих зонах — они будут перекрыты интерфейсом WB.

### Оптимальные зоны для текста

```
┌─────────────────────────┐
│  [СВОБОДНО — WB-иконка] │  ← не трогать
│                         │
│  БРЕНД / НАЗВАНИЕ       │  ← верхняя треть
│                         │
│      [ТОВАР]            │  ← центр
│                         │
│  ХАРАКТЕРИСТИКИ         │  ← нижняя треть (выше плашек WB)
│─────────────────────────│
│  [СВОБОДНО — WB-плашки] │  ← не трогать
└─────────────────────────┘
```

## 4. Категории товаров

### 👕 Одежда и текстиль

**Специфика фото:**
- Обязательно фото на модели (flatlay воспринимается хуже)
- Показать посадку с разных ракурсов: фронт, спина, 3/4
- Детали: строчки, ткань крупным планом, лейблы
- Lifestyle: уместный контекст (прогулка, работа, дом)

**Ключевые характеристики для инфографики:**
- Состав ткани (%)
- Размерная сетка (рост/обхват груди/талии/бедер)
- Уход (стирка, глажка — иконки)
- Сезонность
- Страна производства / бренд

**Типичные ошибки:**
- Фото только на вешалке или flatlay без модели
- Нет размерной сетки → высокий процент возвратов
- Плохо видна фактура ткани
- Модель не соответствует ЦА товара
- Пересвет — ткань "выжигается", теряет цвет

---

### 👟 Обувь

**Специфика фото:**
- Три обязательных ракурса: сбоку (основное), спереди, сзади/снизу
- Фото на ноге (модель или нога-манекен)
- Крупный план: подошва, материал, застёжки
- Lifestyle: в действии (ходьба, активность)

**Ключевые характеристики для инфографики:**
- Материал верха и подошвы
- Таблица размеров (EU/RU, длина стельки в см)
- Тип застёжки
- Сезон / температурный диапазон (для зимней обуви)
- Высота подошвы / каблука

**Типичные ошибки:**
- Нет фото подошвы → покупатель не понимает как будет скользить
- Нет таблицы размеров с длиной стельки → возвраты
- Не видно материал (особенно натуральная кожа vs экокожа)
- Фото только одного ботинка, а не пары

---

### 📱 Электроника и гаджеты

**Специфика фото:**
- Главное фото: товар на белом фоне, все грани видны
- Экран устройства — показать включённым с реальным интерфейсом
- Крупный план: разъёмы, кнопки, индикаторы
- Lifestyle: в реальном использовании (человек работает за ноутбуком)
- Комплектация — обязательно!

**Ключевые характеристики для инфографики:**
- Технические спецификации (CPU, RAM, ёмкость батареи и т.д.)
- Совместимость (iOS/Android, разъёмы)
- Гарантия (срок, тип — официальная/сервисная)
- Ключевые фичи vs конкуренты
- Сертификаты (CE, FCC, IP-рейтинг)

**Типичные ошибки:**
- Экран выключен или отражает фотографа
- Нет информации о гарантии → отпугивает
- Не указана совместимость → возвраты
- Слишком много тех. характеристик — покупатель не технарь, нужны выгоды
- Нет фото всех комплектующих

---

### 🛋️ Товары для дома и мебель

**Специфика фото:**
- Главное фото: товар в интерьере (не на белом фоне)
- Показать масштаб — рядом с человеком или знакомым предметом
- Детали: материал, текстура, фурнитура, способы крепления
- Lifestyle: обустроенное пространство с товаром
- Схема сборки / размеры с подписями (для мебели)

**Ключевые характеристики для инфографики:**
- Габариты (Д×Ш×В в см)
- Материал / покрытие
- Нагрузка / вместимость
- Требуется ли сборка (да/нет, время)
- Цвета и варианты исполнения

**Типичные ошибки:**
- Нет габаритов с подписями → невозможно понять впишется ли
- Интерьер выглядит дёшево → снижает воспринимаемую ценность
- Не показана текстура материала крупным планом
- Нет фото деталей крепления/сборки
- Товар занимает <30% кадра — теряется

---

### 💄 Косметика и уход

**Специфика фото:**
- Состав/INCI — ключевой элемент для инфографики
- Показать консистенцию (крем на пальце, сыворотка капает)
- До/после — если есть реальные результаты
- Lifestyle: процесс нанесения, ванная комната, утренний ритуал
- Крупный план: упаковка, дозатор, этикетка с составом

**Ключевые характеристики для инфографики:**
- Тип кожи / волос (для кого)
- Ключевые ингредиенты и их действие
- Объём / количество применений
- Сертификаты (dermatologically tested, гипоаллергенно)
- Способ применения (шаги 1-2-3)

**Типичные ошибки:**
- Состав только на этикетке мелким шрифтом — нечитаемо
- Нет информации для какого типа кожи/волос
- Нет подтверждения эффективности (до/после, клинические тесты)
- Фото упаковки без демонстрации продукта
- Избыток "научных" терминов без объяснения выгоды

---

### 🧸 Детские товары

**Специфика фото:**
- Безопасность на первом месте — сертификаты в инфографике
- Показать ребёнка в процессе использования (реального возраста из ЦА)
- Размерное соответствие — что подходит для какого возраста
- Материалы — нетоксичность, гипоаллергенность
- Lifestyle: радостный ребёнок, вовлечённые родители

**Ключевые характеристики для инфографики:**
- Возраст (от и до)
- Сертификаты безопасности (ГОСТ, EN, CE)
- Материал / отсутствие вредных веществ (BPA-free и т.д.)
- Размеры / вес
- Развивающие функции (для игрушек)

**Типичные ошибки:**
- Нет сертификатов безопасности → родители не купят
- Возраст указан неправильно или отсутствует
- Мелкие детали не показаны (для игрушек критично)
- Нет реального ребёнка на фото (трудно оценить масштаб)
- Пугающие или нереалистичные цвета

---

### 🏋️ Спорт и фитнес

**Специфика фото:**
- Динамические фото (в движении, упражнение, тренировка)
- Технические детали: материал для потоотведения, швы, усиленные зоны
- Lifestyle: спортзал, улица, бег — релевантный контекст
- Размерная сетка с указанием размера для спортсменов разной комплекции
- Показать сгибаемость/эластичность материала

**Ключевые характеристики для инфографики:**
- Вид спорта / активности
- Состав материала + технология (DryFit, Coolmax и т.д.)
- Размерная сетка (вес + рост + обхват)
- Нагрузка / ударопрочность (для оборудования)
- Сертификаты (для профессионального инвентаря)

**Типичные ошибки:**
- Статичные фото без демонстрации в действии
- Нет материала состава (аллергики и профи смотрят)
- Неправильная размерная сетка → 40%+ возвратов
- Не показана функциональность (карманы, молнии, отражатели)
- Lifestyle со спортсменом не того уровня что ЦА

---

### 🍎 Еда и напитки

**Специфика фото:**
- Food photography: аппетитность важнее точности цвета
- Состав / КБЖУ — обязательно в инфографике
- Срок годности и условия хранения
- Упаковка крупно — покупают глазами
- Lifestyle: сервировка, приготовление, моменты потребления

**Ключевые характеристики для инфографики:**
- Состав (без E-шников или с объяснением)
- КБЖУ на 100г и на порцию
- Вес нетто / количество порций
- Срок годности
- Особые свойства (без сахара, без глютена, органик, веган)

**Типичные ошибки:**
- Плохая съёмка еды — серые, матовые, неаппетитные фото
- Нет КБЖУ — ЗОЖ-аудитория пройдёт мимо
- Состав мелким шрифтом нечитаем
- Нет информации об аллергенах
- Непоказана порция / размер упаковки

## 6. Чеклист качества перед публикацией

### ✅ Технический чеклист

- [ ] Формат файла: JPG / PNG / WEBP (WB) или JPG / PNG (Ozon)
- [ ] Соотношение сторон: 3:4 для WB, 1:1 или 3:4 для Ozon
- [ ] Разрешение: ≥ 700×900px (WB), ≥ 1000×1000px рекомендуется
- [ ] Размер файла: ≤ 10 МБ каждое
- [ ] Цветовая модель: RGB (не CMYK)
- [ ] Главное фото: белый или прозрачный фон

### ✅ Чеклист контента

- [ ] Товар занимает ≥ 20% площади (одежда) / ≥ 10% (обувь/аксессуары)
- [ ] Свободные зоны WB не перекрыты (углы + нижняя полоса)
- [ ] Нет запрещённых слов (Лучший, Топ, №1, Хит, Скидка)
- [ ] Нет цен и процентов скидок
- [ ] Нет логотипов WB, Ozon, конкурентов
- [ ] Текст читаем: шрифт ≥ 16px
- [ ] Максимум 2 разных шрифта
- [ ] Максимум 3-4 цвета в палитре

### ✅ Чеклист структуры карточки

- [ ] Фото 1: главное (Hero Shot) с 3-5 преимуществами
- [ ] Фото 2-3: инфографика с характеристиками
- [ ] Фото 4-5: детали и крупные планы
- [ ] Фото 6: комплектация
- [ ] Фото 7-8: lifestyle / в использовании

## 7. Типичные ошибки

### 🚫 Критичные (блокируют публикацию или снижают конверсию >30%)

1. **Запрещённый текст** — цены, скидки, "Лучший", "Топ" → карточка отклоняется или снижается в поиске
2. **CMYK вместо RGB** — цвета отображаются неправильно, изображение выглядит тусклым
3. **Разрешение ниже минимума** — WB отклоняет или показывает мутное фото
4. **Перекрытые зоны WB** — важные элементы карточки скрыты под интерфейсом платформы
5. **Товар занимает <10% площади** — не проходит модерацию WB

### ⚠️ Серьёзные (снижают конверсию 15-30%)

6. **Нет размерной сетки** для одежды/обуви → высокий процент возвратов (до 40%)
7. **Нет инфографики** — покупатель не получает нужную информацию, уходит к конкуренту
8. **Текст мельче 16px** — нечитаем на мобильном (70%+ трафика)
9. **Более 2 шрифтов** — визуальный хаос, снижает доверие к бренду
10. **Товар снят только в flatlay** (для одежды) — без модели конверсия значительно ниже

### 💡 Недочёты (снижают конверсию 5-15%)

11. **Слабый Hero Shot** — товар не выделяется в каталоге при скролле
12. **Нет lifestyle фото** — покупатель не может представить товар у себя
13. **Слишком много текста в инфографике** — информация не усваивается
14. **Одинаковые ракурсы** — 5 фото с одного угла бесполезны
15. **Несоответствие ЦА** — молодёжный товар снят в стиле для пенсионеров и наоборот
16. **Пересвет или недосвет** — теряется текстура и цвет товара
17. **Неоднородный фон** — тени, пятна, неровности на белом фоне
18. **Нет фото комплектации** — покупатель не знает что получит в заказе
