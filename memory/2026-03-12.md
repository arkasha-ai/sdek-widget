## Penpot + penpot-mcp деплой (17:10–17:42)

### Цель
Поднять penpot-mcp в Dokploy чтобы иметь визуальный фидбек при рисовании в Penpot.

### Проблемы при деплое penpot-mcp
1. `montevive/penpot-mcp:latest` — образа нет на Docker Hub
2. Nixpacks/GitHub Provider error — та же ошибка что была с Penpot (sourceType=github)
3. FastMCP биндится на `127.0.0.1` по умолчанию — Traefik не может достучаться
4. PORT env var игнорируется — FastMCP передаёт `host="127.0.0.1"` в Settings явно, env vars не помогают
5. Patch через Dockerfile inline — экранирование кавычек ломало скрипт

### Решение
- Dockerfile с `printf` → wrapper-скрипт `/usr/local/bin/penpot-mcp-patched`
- Monkey-patch `FastMCP.__init__` чтобы `host` defaulted на `0.0.0.0`
- Порт: 8000 (FastMCP SSE default, не 5000!)
- SSE путь: `/sse` (FastMCP default: `mcp.settings.sse_path = "/sse"`)
- Compose ID: `wfKJcRVbOv2hRMDh6lk3W`
- Domain: `penpot-mcp.jakeberrimor.com` → container port 8000

## 23:40–23:48 — Penpot text-align fix (v6 Nota app)

### Проблема
Несколько попыток (v1-v5) — text-align не работал. Пробовал:
- `"~:align":"center"` — не работает (неправильный ключ)
- `"~:text-align":"center"` в text node — не работает (неправильный уровень)

### Решение — источник истины: Penpot source code
Пришёл к правильному ответу через Penpot source: `common/src/app/common/types/text.cljc`
```clojure
(def paragraph-attrs
  (d/concat-vec
   text-align-attrs    ; [:text-align]
   text-direction-attrs))
```
**`text-align` живёт в `paragraph` (не в text node, не `~:align`)!**

### Правильная структура
```python
"~:content": {
    "~:type": "root",
    "~:children": [{"~:type": "paragraph-set", "~:children": [{
        "~:type": "paragraph",
        "~:text-align": "center",   # ← ЗДЕСЬ, на уровне paragraph
        "~:children": [{
            "~:text": "Hello",
            "~:font-size": "18",
            "~:fills": [...]
        }]
    }]}]
}
```
