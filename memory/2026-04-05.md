### Финальная архитектура (v3)

**Концепция:** `arkadius` ЗАВИСИТ от `arkadius-admin`. Админка поставляет LLM (проксирует Anthropic) и Sandbox. Agent сам по себе лёгкий — sandbox поднимается только когда нужен exec/browser.

**Репозитории:**
- `arkadius` (ZnaemAI) — клиент + агент: Next.js UI, FastAPI, Agent Core, СВОЯ локальная БД для памяти, каналы
- `arkadius-admin` (ZnaemAI) — серверная инфра: LLM proxy, billing, sandbox pool, browser pool, monitoring, admin UI
- `arkadius-node-server` — Rust daemon (без изменений)

**Режимы деплоя:**
- SaaS: один arkadius multi-tenant + arkadius-admin на нашем сервере
- On-prem: arkadius у клиента, подключается к нашему admin за LLM/sandbox
- Enterprise: полностью автономный (свой admin + свой arkadius)

**Ключевое правило:** `ADMIN_URL` и `ADMIN_API_KEY` обязательные — агент падает при старте если не заданы. Без админки работать не может.
