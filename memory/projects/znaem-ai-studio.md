## Кейсы

1. **Агент для юриста** — RAG, Парсинг, Росреестр API, Голосовой ввод, Document AI
2. **SyncVoice** — Синхронный перевод речи в реальном времени, STT→TTS, <2 сек, 4 языка, on-premise
3. **Logera** — Корпоративная база знаний с семантическим поиском (векторный поиск + Whisper)
4. **Sales Coach** — AI-тренер для менеджеров, real-time подсказки в наушник, анализ разговора
