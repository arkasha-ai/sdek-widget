## Запросы клиента

### План 1: AI-агент для продаж индор-рекламы ✅ (перспективный)
- Поиск ЛПР в соцсетях: TenChat, FB, LinkedIn, Telegram
- Исходящие рассылки: почта, ЛС, возможно звонки
- Коммуникация + занесение в CRM (Битрикс24)
- Напоминания по таймеру
- Передача квалифицированных лидов менеджеру-человеку

### План 2: AI-агент для политической агитации ⚠️ (риски)
- Взаимодействие с электоратом через соцсети
- Рассылки поздравлений и предвыборных обещаний
- Обработка входящих / переключение на человека
- Парсинг и мониторинг соцсетей по ключевым запросам

## Первичная оценка
- **План 1** — реализуемо, рынок есть
- **План 2** — юридически серая зона, репутационные риски для ZnaemAI
