## 4. Главный экран (чат)

```
┌─────────────────────────────────────────────────────────────────┐
│ ☰│ Ассистент               💰 245 кр. │ Claude Sonnet ▾ │ ⚙️  │
├──┼──────────────────────────────────────────────────────────────┤
│  │                                                              │
│S │  ┌─ agent ──────────────────────────────────────────┐        │
│I │  │ Привет, Денис! Я ваш персональный ассистент.     │        │
│D │  │ Чем могу помочь?                                  │        │
│E │  └──────────────────────────────────────── 14:20 ────┘        │
│B │                                                              │
│A │                        ┌─ user ──────────────────────┐       │
│R │                        │ Найди информацию о Next.js 15│       │
│  │                        └──────────────────── 14:21 ───┘       │
│  │                                                              │
│  │  ┌─ agent ──────────────────────────────────────────┐        │
│  │  │ 🔍 Ищу в интернете...                            │        │
│  │  │                                                   │        │
│  │  │ Next.js 15 вышел в октябре 2024 и включает:      │        │
│  │  │ • React Server Components по умолчанию            │        │
│  │  │ • Turbopack в stable                              │        │
│  │  │ • Partial Prerendering (экспериментально)         │        │
│  │  │ ...                                    ■ стоп     │        │
│  │  └──────────────────────────────── 14:21 ─ 0.8 кр. ─┘        │
│  │                                                              │
├──┼──────────────────────────────────────────────────────────────┤
│  │ 📎 │ Напишите сообщение...                        │ ➤ Send │
└──┴──────────────────────────────────────────────────────────────┘
```

**Sidebar (слева, сворачивается):**
- Новый чат
- История сессий (список по датам)
- Файлы
- Расходы
- Настройки

**Хедер:**
- Имя агента
- Баланс (кликабельный → /billing)
- Селектор модели (dropdown)
- Иконка настроек

**Область чата:**
- Сообщения user (справа, другой цвет) и agent (слева)
- Время у каждого сообщения
- Стоимость у ответов агента (мелким шрифтом)
- Индикатор tool use: «🔍 Ищу...», «📄 Читаю файл...»
- Кнопка «■ стоп» во время генерации

**Поле ввода:**
- Кнопка 📎 (загрузка файла)
- Textarea (авторесайз)
- Кнопка отправки (➤)
- Shift+Enter = перенос, Enter = отправка

**Состояния:**
- **Loading (cold start):** «Агент просыпается...» (пульсирующий индикатор, 1-2 сек)
- **Empty (первый визит):** приветственное сообщение от агента + подсказки-кнопки: «Что ты умеешь?» / «Помоги с задачей» / «Проанализируй файл»
- **Error (WebSocket):** banner «Потеряно соединение. Переподключение...» + автоматический reconnect
- **Error (нет кредитов):** сообщение от агента «Баланс исчерпан» + кнопка «Пополнить»
- **Typing:** три пульсирующие точки перед первым токеном

- **Error (return):** красный toast «Оплата не прошла. Попробуйте ещё раз»
