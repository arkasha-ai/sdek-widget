## Суть продукта

Сервис для быстрого создания сайтов через AI. Клиент описывает что хочет — получает готовый сайт, развёрнутый на наших серверах. Поддерживаем сами.

**Типы сайтов:** лендинги, интернет-магазины  
**Целевая аудитория:** малый бизнес, ИП, фрилансеры, стартапы  
**Позиционирование:** дешевле студий, быстрее нанятых разработчиков, умнее конструкторов

---

## Пользовательский путь

```
1. Клиент находит нас (сайт студии / соцсети / нетворк)
2. Пишет нам: "хочу сайт, вот что мне нужно..."
3. Мы (или AI-агент) задаём уточняющие вопросы:
   - Тип сайта (лендинг / магазин)
   - Ниша и продукт
   - Стиль (референсы)
   - Цветовая схема, тональность
   - Нужен ли домен
4. AI генерирует сайт → превью клиенту
5. Клиент согласует / просит правки
6. Деплоим на наши серверы
7. Клиент получает ссылку + доступ к кабинету
8. Мы поддерживаем (обновления, правки, хостинг)
```

## Технический стек (предварительно)

### Генерация
- **LLM:** Claude Sonnet / Qwen Coder для генерации кода
- **Шаблонная база:** набор готовых компонентов (Hero, Features, Pricing, Footer, Product Card и т.д.)
- **Стек сайтов:** HTML/CSS/JS (статика) или Next.js / SvelteKit для магазинов

### Превью и деплой
- **Превью:** iframe sandbox (мгновенный рендер)
- **Деплой:** автоматически на наши серверы (VPS, Dokploy или аналог)
- **Домены:** subdomain вида `client.znaem.ai` + поддержка custom domain

### Хранение и управление
- **БД:** PostgreSQL (клиенты, сайты, версии)
- **Файлы:** S3-совместимое хранилище (медиа клиента)
- **Панель клиента:** простой кабинет — посмотреть сайт, запросить правки

### Коммуникация с клиентом
- **MVP:** Telegram (общаемся в чате, Аркаша принимает заявки)
- **Продакшн:** форма на сайте + Telegram-бот для статуса заказа

## MVP (минимальная версия)

**Цель MVP:** закрыть первые 3-5 заказов вручную, проверить спрос

**Что входит в MVP:**
- [ ] Промпт-система для генерации лендинга (HTML/CSS/JS, адаптивный)
- [ ] Генерация через API (Claude/Qwen)
- [ ] Ручной деплой на VPS через Dokploy
- [ ] Превью по ссылке перед деплоем
- [ ] Шаблоны для 3-5 ниш (кафе/ресторан, услуги, товар, магазин одежды, IT-компания)

**Что НЕ входит в MVP:**
- Самостоятельная генерация клиентом (всё через нас)
- Автоматический деплой
- Личный кабинет клиента
- Оплата онлайн

**Срок MVP:** 1-2 недели

## Риски

1. **Качество кода** — AI генерирует красиво, но может ломаться. Решение: шаблонная основа + AI только для кастомизации
2. **Масштабирование** — ручной процесс не масштабируется. Решение: автоматизировать на этапе 2
3. **Поддержка** — клиенты будут просить правки постоянно. Решение: чёткий SLA, лимиты на правки в тарифе
