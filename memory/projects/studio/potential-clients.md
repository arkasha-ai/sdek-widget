## 1. Пензенские IT-компании (5 шт)

### 1.1 JETSTYLE Пенза (веб-студия)
- **Почему подходит:** Сильный дизайн и фронт, но нет AI-компетенций — идеальный партнёр для субподряда
- **Месседж:** «Видел ваши проекты — крутой дизайн; если клиенты просят AI-фичи, могу закрыть эту часть как субподрядчик.»

### 1.2 Первый БИТ Пенза (1С-франчайзи)
- **Почему подходит:** Клиенты на 1С массово хотят автоматизацию документооборота и отчётов — AI идеально ложится
- **Месседж:** «Делаю AI-автоматизацию для 1С-клиентов: генерация документов, классификация, умный поиск — без переписывания 1С.»

### 1.3 СофтМастер (интегратор, Пенза)
- **Почему подходит:** Системная интеграция без AI-направления — могут продавать AI как допуслугу своим клиентам
- **Месседж:** «Ваши клиенты уже спрашивают про AI? Могу усилить ваше предложение AI-модулями под ключ.»

### 1.4 Web-студия "Пиксель" (Пенза)
- **Почему подходит:** Классическая веб-студия, делает сайты и CRM — AI-чатботы и поиск это апсейл для их клиентов
- **Месседж:** «Добавляю AI-чатботы и умный поиск к сайтам ваших клиентов — вы продаёте, я делаю, white-label.»

### 1.5 Гравитон / Gravity (ERP-разработка)
- **Почему подходит:** Уже работал с ними, знаю продукт — можно расширить AI-интеграции на коммерческой основе
- **Месседж:** «Готов масштабировать AI-интеграции в Gravity: автоклассификация, генерация заявок, предиктивная аналитика.»

## 2. Бизнес, который выиграет от AI (5 шт)

### 2.1 Частные клиники / медцентры (Пенза)
- **Почему подходит:** Запись, сортировка обращений, предварительная диагностика по симптомам — AI снижает нагрузку на регистратуру
- **Месседж:** «AI-бот для записи и сортировки обращений — минус 60% нагрузки на регистратуру, работает 24/7.»

### 2.2 Юридические компании / адвокатские бюро
- **Почему подходит:** Тонны документов, поиск прецедентов, генерация типовых договоров — RAG-поиск даёт огромный ROI
- **Месседж:** «Семантический поиск по вашей базе документов и автогенерация типовых договоров — экономия 10+ часов в неделю.»

### 2.3 HR-агентства / крупные HR-отделы
- **Почему подходит:** Скрининг резюме, первичный контакт с кандидатами, FAQ для сотрудников — стандартные AI-задачи
- **Месседж:** «AI-скрининг резюме + чат-бот для кандидатов: обрабатывает 100 откликов за минуты, а не дни.»

### 2.4 Логистические компании
- **Почему подходит:** Обработка заявок, маршрутизация, классификация грузов — много рутины которую AI автоматизирует
- **Месседж:** «Автоматизация обработки заявок и маршрутизации через AI — быстрее, без ошибок, 24/7.»

### 2.5 Ритейл / e-commerce (средний бизнес)
- **Почему подходит:** Рекомендации, умный поиск по каталогу, чат-поддержка — прямой рост конверсии
- **Месседж:** «AI-поиск по каталогу + персональные рекомендации — у похожих магазинов конверсия растёт на 15-25%.»

## 3. Студии без AI-экспертизы для субподряда (5 шт)

### 3.1 Студия Артемия Лебедева (дизайн + веб)
- **Почему подходит:** Топ-дизайн, но AI-проекты отдают на субподряд — высокие бюджеты, интересные задачи
- **Месседж:** «Беру AI-часть ваших проектов на субподряд: от прототипа до продакшена, NDA и white-label.»

### 3.2 Globus IT (Пенза/Саратов, аутсорс)
- **Почему подходит:** Аутсорс-разработка без выделенного AI-направления — их клиенты начинают просить AI
- **Месседж:** «Усилю ваш аутсорс AI-экспертизой: LLM-интеграции, RAG, автоматизация — подключаюсь к вашей команде.»

### 3.3 Red Collar (digital-агентство)
- **Почему подходит:** Делают сложные digital-продукты, AI — логичное расширение их предложения
- **Месседж:** «AI-субподряд для ваших digital-проектов: чат-боты, поиск, автоматизация — под вашим брендом.»

### 3.4 Студия Флаг (Москва, веб-продакшн)
- **Почему подходит:** Среднего размера продакшн-студия с хорошим потоком клиентов, но без ML-команды
- **Месседж:** «Если клиенты просят "добавить AI" — я закрываю эту часть быстро и под ключ, работаю как ваша AI-команда.»

### 3.5 Charm (digital-студия, Казань)
- **Почему подходит:** Региональная студия с растущим портфелем — AI-субподряд позволит конкурировать с московскими агентствами
- **Месседж:** «AI-фичи для ваших проектов без найма ML-инженера — субподряд, фикс за задачу, быстрый старт.»

## 4. Потенциальные Upwork-клиенты (5 профилей задач)

### 4.1 "Build RAG chatbot for our documentation"
- **Почему подходит:** Прямое попадание в экспертизу: RAG + LLM + Python — core компетенция
- **Месседж:** «Built production RAG systems with Qdrant/FAISS — can deliver a working prototype in 1 week.»

### 4.2 "AI agent for customer support automation"
- **Почему подходит:** Опыт с автономными агентами (Arkasha), multi-tool orchestration, memory management
- **Месседж:** «I build AI agents with long-term memory and tool orchestration — shipped autonomous systems in production.»

### 4.3 "LLM integration into existing SaaS product"
- **Почему подходит:** Интеграция LLM в существующие продукты — именно то, что делал для Gravity
- **Месседж:** «Integrated LLM pipelines into enterprise ERP — document generation, classification, search — clean API, no rewrites.»

### 4.4 "Need a full-stack developer with AI/ML experience"
- **Почему подходит:** Full-stack (React + Python/FastAPI) плюс AI — редкое и ценное сочетание на Upwork
- **Месседж:** «7+ years full-stack, 2+ years AI/LLM — React, Python, FastAPI, deployed RAG and agent systems in production.»

### 4.5 "Automate document processing with AI"
- **Почему подходит:** Генерация и обработка документов — прямой опыт с заявками Gravity
- **Месседж:** «Built AI document pipelines: classification, extraction, generation from templates — FastAPI + LangChain, production-ready.»

## Приоритеты

1. **Быстрые деньги:** Upwork (4.1–4.5) — начать подавать заявки сразу
2. **Локальная сеть:** Пензенские IT (1.1–1.5) — личные встречи, доверие
3. **Масштаб:** Субподряд у студий (3.1–3.5) — стабильный поток задач
4. **Средний чек:** Бизнес + AI (2.1–2.5) — через бесплатный AI-аудит как лид-магнит
