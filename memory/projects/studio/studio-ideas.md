## Услуги (согласованные)

1. **Агент под ключ** — персональный AI-ассистент для сотрудника/отдела. Фикс: 150-300К ₽
2. **AI-автоматизация процесса** — берём одну боль и автоматизируем. Фикс: 100-200К ₽
3. **AI-аудит** — бесплатно/символически, конверсия в платный контракт
4. **AI-поддержка для SaaS** — агент с доступом к логам/данным клиента, закрывает 70-80% тикетов. Аналог Vercel AI support
5. **White-label агент (хостинг)** — деплой и поддержка агента на нашей инфре. 30К/мес + наценка 50% на токены
6. **AI-разработка сайтов** — лендинги и интернет-магазины через AI + размещение и поддержка на наших серверах. Клиент пишет нам → мы делаем → деплоим → поддерживаем.

## Идеи продуктов

### 🟢 AI для маркетплейсов (приоритет)
**Суть:** AI-бот для упаковки товаров на WB/Ozon — фото, видео, инфографика, описания
**Рынок:** Конкуренты есть, рынок занят но не закрыт
**Конкуренты:**
- Fabula AI — генерация фона, инфографика, анализ конкурентов (самый серьёзный)
- WILDA — быстрая генерация визуала
- SUPA — комплексная оптимизация карточек
- WBCARD — автоматизация продвижения
- Seller Moon — комбайн аналитика+контент, от 499₽/мес
- Все — шаблонные сервисы (пользователь делает всё сам через интерфейс)
**Наша незакрытая ниша:** Telegram-агент который сам всё делает — загрузил фото, написал задачу, получил фон/инфографику/описание/видео. Без интерфейса, без шаблонов.
**Целевой клиент:** Ленивые продавцы с деньгами (средний/крупный сегмент)
**Решение:** MVP на коленке за неделю → смотрим реакцию
**Статус:** Миша изучает конкурентов

### 🟡 ГДЗ с AI
**Суть:** Помощник для решения домашних заданий
**Проблема:** Рынок очень конкурентный (Math AI, Photomath, GigaChat). Сложно без маркетбюджета
**Статус:** На паузе

### 🟡 AI бот для откликов на HH
**Суть:** Автоматические отклики на вакансии
**Проблема:** Серая зона (HH банит массовые отклики), b2c с маленьким чеком
**Статус:** Side product, не приоритет

### 🟢 AI-разработка сайтов + хостинг (2026-03-19, РЕШЕНО добавить в услуги)
**Суть:** AI-конструктор сайтов с генерацией кода + деплой на наши серверы. Пользователь описывает что хочет → получает готовый сайт.
**Рынок:** v0 и Lovable в РФ почти не используются (языковой барьер, оплата). Локальный аналог с рублёвой оплатой и хостингом в РФ — реальная ниша.
**Стек:** LLM генерирует код → превью в iframe → деплой одной кнопкой на свои серверы
**Монетизация:** Подписка или pay-per-site
**Риск:** Качество результата — production-ready vs "выглядит красиво в демо, ломается в реальности" (проблема Lovable)
**Инициатор:** Миша
**Статус:** ✅ Решено добавить в услуги студии. AI генерирует, деплоим на своих серверах.

### 🟡 AI-помощник для поиска квартиры
**Суть:** Telegram-бот/агент, который ищет квартиру по параметрам пользователя — парсит ЦИАН, Авито, ЖК-сайты, фильтрует по критериям (район, цена, этаж, инфраструктура), присылает топ вариантов с анализом и ссылками. Умеет объяснять "почему этот вариант хуже того".
**Нюансы:** ЦИАН/Авито имеют защиту от парсинга, нужен либо официальный API (платный) либо осторожный парсинг. Рынок есть — люди тратят часы на поиск.
**Потенциал:** b2c подписка (199-499₽/мес) или b2b для риэлторов
**Статус:** Идея от Миши — оценить рынок
