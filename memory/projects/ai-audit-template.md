### Рекомендации по блокам

**Рутина и автоматизация (сумма 10+):**
- → AI-агенты для обработки типовых задач
- → Автоматический перенос данных между системами (интеграции + LLM)
- → Документирование процессов с помощью AI, снижение bus factor
- **Типичный ROI:** экономия 2-4 часа/день на сотрудника, окупаемость за 1-2 месяца

**Работа с клиентами (сумма 10+):**
- → AI-чатбот для первой линии поддержки (закрывает 60-80% типовых вопросов)
- → Автоматическая маршрутизация обращений
- → Персонализация на основе истории взаимодействий
- **Типичный ROI:** скорость ответа ×5-10, NPS +15-25 пунктов

**Данные и аналитика (сумма 10+):**
- → RAG-система по внутренней базе знаний (поиск по всем документам на естественном языке)
- → AI-аналитика: автоматические инсайты из данных
- → Суммаризация встреч, звонков, переписок
- **Типичный ROI:** время на поиск информации -70%, качество решений растёт

**Контент и документы (сумма 7+):**
- → Автогенерация КП, отчётов, описаний по шаблонам
- → AI-помощник для контент-маркетинга
- → Автоматическая подготовка презентаций
- **Типичный ROI:** время на документ -60-80%, больше контента без найма

**Операции и масштаб (сумма 13+):**
- → Автоматизация процессов для масштабирования без линейного найма
- → AI-контроль качества (проверка ошибок, аномалий)
- → Предиктивная аналитика для упреждения проблем
- **Типичный ROI:** готовность к росту ×2-3 без пропорционального увеличения штата
