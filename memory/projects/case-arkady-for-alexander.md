# Кейс: Персональный AI-агент для юриста

## Суть

Персональный ассистент **Аркадий** — отдельный изолированный AI-агент, развёрнутый для конкретного пользователя (юрист Александр Воробьёв). Работает в Telegram, имеет собственную память, инструменты и правила поведения.

---

## Что умеет агент

### 1. Юридические исследования
- Поиск судебной практики через **КонсультантПлюс** (браузерная авторизация)
- Структурированный вывод: Фабула / Позиция сторон / Решение / Реквизиты + ссылка
- Пример: 4 дела ВС РФ и КС РФ по спорам застройщик/площадь за сессию

### 2. Работа с документами
- Анализ PDF, DOCX (договоры, тарифные сметы, земельные выписки)
- Генерация документов: договоры, обращения, протоколы
- Пример: PDF-презентация тарифов УК «Высота-Сервис» с таблицами из 2 документов

### 3. Кадастровый анализ
- Парсинг данных с Росреестра/roscadaster.com (обход GeoIP-блокировок)
- Анализ кадастровых стоимостей, форм собственности, ВРИ
- Пример: 13 земельных участков (76,8 га), флаги рисков, сводная таблица

### 4. Поиск по судебным базам
- Работа с ГАС Правосудие, сайтами судов, ФССП
- Решение проблем с капчами и GeoIP-блокировками
- Решение исполнительных листов по номеру

### 5. Задачи в SingularityApp
- Интеграция с личным планировщиком пользователя через API
- Добавление задач, заметок в нужном формате

### 6. Контент-стратегия
- Рекомендации по Telegram-каналам (структура, контент, рубрики)
- Написание постов для профессионального канала юриста

---

## Техническая архитектура

- **Изолированный workspace** — отдельная директория, отдельная память
- **Собственный браузерный профиль** (`arkady-alexander`) — история, куки, сессии
- **Персональная MEMORY.md** — фиксирует данные, правила поведения, интеграции
- **Правила доступа** — агент не видит память и данные других пользователей
- **Два владельца** — Денис (технический) + Александр (конечный пользователь)

## Что это показывает

- **Изолированность** — один агент = один пользователь, данные не смешиваются
- **Доменная экспертиза** — агент адаптирован под юридическую работу
- **Интеграции** — КонсультантПлюс, Росреестр, ФССП, SingularityApp, браузер
- **Масштабируемость** — такой агент можно развернуть для любого специалиста
