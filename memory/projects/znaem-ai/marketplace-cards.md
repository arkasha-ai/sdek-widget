## Итоговый пайплайн

### Шаг 1 — Приём товара
- Пользователь загружает фото товара + описание (что это, для кого, ключевые свойства)
- Анализируем фото: определяем товар, аудиторию, сценарии использования
- Предлагаем план из 5-6 карточек (истории) → ждём одобрения

### Шаг 2 — Подготовка фото товара
- Убираем фон через Replicate `lucataco/remove-bg`
- Если есть артефакты (руки, пальцы) → кроп верхней части
- **Правило:** фото товара не изменять и не видоизменять

### Шаг 3 — Генерация lifestyle сцен
Два инструмента через Replicate:

**FLUX Kontext Pro** (`black-forest-labs/flux-kontext-pro`)
- ~$0.04/фото
- Хорошее качество, быстро (~30 сек)
- Подходит для большинства товаров

**Nano Banana Pro** (`google/nano-banana-pro`)
- ~$0.15/фото (1K/2K), $0.30 (4K)
- Лучше качество: реалистичнее модели, металл/текстуры чище
- Подходит для флагманских карточек, мелких деталей, украшений

Входные данные: `input_image` (base64 фото товара) + промпт сцены.

### Шаг 4 — Финальная карточка (HTML/CSS → скриншот)
- Пишем HTML с фото как фон
- Добавляем: заголовок, подзаголовок, чипы с характеристиками
- Скриншот через браузер Chromium → JPEG 1080×1080
- Шрифты Google Fonts (Unbounded, Manrope, Cormorant, Space Grotesk и др.)
- **Правило:** текст не перекрывает товар / модель

---

## Правила дизайна

1. **Фото товара — священно.** Не генерировать, не менять цвет, не деформировать
2. **Стиль под товар.** Каждый товар = своя типографика и палитра:
   - Тапочки → тёплые бежевые тона, Unbounded + Manrope
   - Зажимы → деловой минимализм, Space Grotesk + Space Mono, синий акцент
   - Пижама/одежда → женский стиль, Cormorant Garamond, розовый акцент
   - Украшения/брелки → ювелирный стиль, Playfair Display + Inter
3. **Текст не перекрывает товар** — только в свободных зонах кадра
4. **Шрифты крупные** — заголовки от 62px+, подписи от 22px+
5. **Блоки текста выделены** — backdrop-blur, border, контрастный фон
6. **Масштаб в промпте** — всегда указывать реальный размер товара
7. **Проверка деформаций** — перед отправкой смотреть на руки/пальцы/форму товара
8. **Один раз отправлять** — не дублировать изображения

## Рассказывай историю, не просто показывай товар

Пользователь даёт фото → ИИ создаёт историю:
- Утреннее пробуждение (тапочки, пижама)
- Вечерний уют на диване
- Прогулка по городу (шапка, брелок на сумке)
- Рабочий стол в порядке (зажимы)
- Кофе в кафе

Цель: покупатель видит себя в этом образе, а не просто товар.

- Нанабанана: ~17₽

## Флоу бота (финальный)

1. Юзер → фото товара + параметры (кол-во карточек, качество)
2. Бот генерирует → отправляет превью (можно сжатые)
3. Юзер одобряет → бот отправляет **оригиналы без сжатия** 1080×1080
4. Последнее сообщение бота: **"Оцените работу от 1 до 10 и расскажите что понравилось, а что можно улучшить"**

Аркаша в боевом боте = прототип. Боевой бот: Python/Node.js → Replicate API напрямую.

## Правила общения с юзером (ВАЖНО)

- **Никогда не оценивать карточки вслух** — никаких "8/10", "вышло хорошо", "9 из 10", никаких оценок качества в чате с клиентом
- **Никогда не раскрывать себестоимость** — ни стоимость генерации, ни названия моделей с ценами, ни "это стоило X рублей"
- Показывать результат → спрашивать что поправить
- **Перед первой генерацией уточнять:** сколько карточек нужно (3/5/7) и какое качество (стандарт / премиум)

## Уроки дня

- Нанабанана лучше держит детали металла и реализм модели
- FLUX иногда теряет масштаб мелких предметов → указывать размер в промпте явно
- Для lifestyle с одеждой → FLUX достаточно, для украшений → нанабанана
- Деформации рук/пальцев — регулярно проверять перед отправкой
- HTML/CSS финальная карточка — правильный подход, Pillow был уровнем Paint
- Каждый товар требует своего дизайн-языка, шаблоны не работают
