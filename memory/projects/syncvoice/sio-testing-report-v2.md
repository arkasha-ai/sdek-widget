## 🔴 Критичные находки

### 1. Обязательная регистрация для оформления заказа

**Приоритет:** Высокий  
**Влияние на бизнес:** **Критическая потеря конверсии** (~30-40% по статистике e-commerce)

**Проблема:**  
Нельзя оформить заказ как гость. Обязательна регистрация с заполнением ФИО, телефона, email, пароля.

![Форма авторизации при checkout](/home/clawdbot/.openclaw/media/browser/a6b907f0-b6fd-453c-a279-78bb81286896.png)

**Сценарий:**
1. Пользователь добавляет товары в корзину
2. Нажимает "Оформить заказ"
3. Видит форму регистрации (3 шага: личные данные, адрес, пароль)
4. **Бросает корзину** (слишком долго, лень регистрироваться)

**Рекомендация:**
- Добавить **гостевой checkout** (заказ без регистрации)
- Или упростить регистрацию: объединить в 1 шаг, убрать лишние поля
- Предложить регистрацию ПОСЛЕ оформления заказа

## 💡 Рекомендации по приоритетам

### 🔥 Критично (влияние на конверсию >20%)

**1. Добавить гостевой checkout**
- **Влияние:** +30-40% конверсия (статистика e-commerce)
- **Сложность:** Средняя (неделя разработки)
- **ROI:** Очень высокий

**2. Упростить регистрацию**
- Если гостевой checkout невозможен, объединить 3 шага регистрации в 1
- Убрать необязательные поля (регистрационный номер)
- **Влияние:** +15-20% конверсия

### ⚠️ Важно (UX улучшения)

**3. Добавить прогресс-индикатор в корзине**
- Показывать сколько осталось до минимальной суммы (1000₽)
- Пример: "Добавьте ещё товаров на 850₽ для оформления заказа"
- **Влияние:** Улучшение UX, мотивация добавить товары

**4. Проверить мобильную версию**
- Тестирование проводилось на desktop
- Рекомендуется отдельное тестирование на мобильных

### ℹ️ Низкий приоритет

**5. Оптимизация форм**
- Автозаполнение адреса (DaData API)
- Подсказки при вводе email
