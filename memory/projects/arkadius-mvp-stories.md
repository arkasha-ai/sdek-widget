# Аркадиус — MVP User Stories

> **Версия:** 1.0 | **Дата:** 2026-03-19  
> **Scope:** MVP v0.1

---

## US-1: Регистрация и онбординг

### US-1.1: Регистрация по email

**Как** новый пользователь,  
**я хочу** зарегистрироваться по email и паролю,  
**чтобы** получить доступ к персональному AI-ассистенту.

**Acceptance Criteria:**
1. Форма содержит поля: email, пароль, подтверждение пароля
2. Пароль ≥ 8 символов, содержит буквы и цифры; при несоответствии — inline-ошибка
3. При дублировании email — сообщение «Этот email уже зарегистрирован»
4. После успешной регистрации — автоматический вход и редирект на онбординг
5. Отправляется письмо подтверждения email (не блокирует использование на 24ч)

### US-1.2: Вход через Google OAuth

**Как** пользователь,  
**я хочу** войти через Google-аккаунт,  
**чтобы** не запоминать отдельный пароль.

**Acceptance Criteria:**
1. Кнопка «Войти через Google» на экране входа
2. При первом входе через Google — автосоздание аккаунта + редирект на онбординг
3. При повторном входе — редирект на главный экран (чат)
4. Если email Google совпадает с существующим — предложение привязать аккаунт

### US-1.3: Онбординг — создание агента

**Как** новый пользователь,  
**я хочу** пройти короткий онбординг и настроить своего агента,  
**чтобы** ассистент сразу знал обо мне базовую информацию.

**Acceptance Criteria:**
1. Онбординг из 3 шагов: имя пользователя → имя агента → выбор основной задачи (работа / учёба / личное)
2. Каждый шаг — один экран, кнопки «Далее» / «Назад» / «Пропустить»
3. По завершении создаётся workspace агента с предзаполненными SOUL.md и USER.md
4. Выбирается модель по умолчанию (Claude Sonnet)
5. Пользователю начисляется приветственный бонус — 50 кредитов (для пробы)

## US-2: Пополнение баланса (prepaid кредиты)

### US-2.1: Просмотр баланса

**Как** пользователь,  
**я хочу** видеть текущий баланс кредитов,  
**чтобы** понимать, сколько ещё могу использовать агента.

**Acceptance Criteria:**
1. Баланс отображается в хедере на всех страницах (формат: «💰 245 кр.»)
2. При балансе < 50 кредитов — жёлтый индикатор
3. При балансе = 0 — красный индикатор + ссылка «Пополнить»
4. Клик по балансу ведёт на страницу пополнения

### US-2.2: Пополнение через ЮKassa

**Как** пользователь,  
**я хочу** пополнить баланс банковской картой,  
**чтобы** продолжить использование агента.

**Acceptance Criteria:**
1. Экран пополнения предлагает 4 пакета: 199₽, 499₽, 999₽, 2999₽ + произвольная сумма
2. Для каждого пакета отображается количество кредитов и бонус (если есть)
3. При нажатии «Оплатить» — редирект на виджет ЮKassa
4. После успешной оплаты — возврат на сайт, баланс обновлён, уведомление «+550 кредитов»
5. При ошибке оплаты — сообщение с предложением повторить

### US-2.3: Уведомление о низком балансе

**Как** пользователь,  
**я хочу** получать предупреждение когда кредиты заканчиваются,  
**чтобы** не прерываться посреди важной задачи.

**Acceptance Criteria:**
1. При балансе < 20 кредитов — всплывающий баннер в чате «Кредиты заканчиваются»
2. При балансе = 0 — агент отправляет сообщение «Баланс исчерпан. Пополните для продолжения» + кнопка
3. Агент не может отправлять запросы к LLM при нулевом балансе
4. Уже начатый ответ (стриминг) доставляется до конца, даже если баланс ушёл в минимальный минус

## US-3: Создание и настройка агента

### US-3.1: Настройка имени и личности

**Как** пользователь,  
**я хочу** задать агенту имя и стиль общения,  
**чтобы** взаимодействие было приятным и персональным.

**Acceptance Criteria:**
1. В настройках: поле «Имя агента» (по умолчанию «Ассистент», макс. 50 символов)
2. Текстовое поле «Системный промпт» с плейсхолдером-примером (макс. 2000 символов)
3. Изменения сохраняются по кнопке «Сохранить» и применяются к следующему сообщению
4. Предустановленные шаблоны стиля: «Формальный», «Дружелюбный», «Краткий»

### US-3.2: Выбор модели

**Как** пользователь,  
**я хочу** выбрать AI-модель для агента,  
**чтобы** управлять балансом между качеством и стоимостью.

**Acceptance Criteria:**
1. Список доступных моделей с описанием: Claude Sonnet (рекомендуемая), GPT-4o, Qwen Plus
2. Для каждой модели: название, описание (2 строки), примерная стоимость за сообщение
3. Модель можно менять в настройках и быстрым переключателем в чате
4. Смена модели влияет только на новые сообщения, не на историю
5. При выборе дорогой модели — предупреждение о стоимости

## US-4: Текстовый чат с агентом

### US-4.1: Отправка сообщения и получение ответа

**Как** пользователь,  
**я хочу** писать сообщения агенту и получать ответы в реальном времени,  
**чтобы** решать свои задачи через естественный диалог.

**Acceptance Criteria:**
1. Поле ввода с поддержкой многострочного текста (Shift+Enter — перенос, Enter — отправка)
2. Ответ агента стримится в реальном времени (посимвольно/по-токенно через WebSocket)
3. Markdown в ответах рендерится: заголовки, списки, код, таблицы, ссылки
4. Во время генерации ответа — кнопка «Остановить» для отмены
5. Задержка до первого токена ≤ 2 секунды (для горячего агента)

### US-4.2: История чата

**Как** пользователь,  
**я хочу** видеть историю переписки с агентом,  
**чтобы** вернуться к прошлым ответам и задачам.

**Acceptance Criteria:**
1. История загружается при открытии чата (последние 50 сообщений)
2. Скролл вверх подгружает старые сообщения (бесконечный скролл, по 50)
3. У каждого сообщения — время отправки (формат: «14:23» или «вчера, 22:10»)
4. Агент помнит контекст предыдущих сессий (через memory-систему OpenClaw)
5. Поиск по истории — строка поиска в верхней части чата

### US-4.3: Использование инструментов

**Как** пользователь,  
**я хочу** чтобы агент мог искать в интернете и выполнять действия,  
**чтобы** получать актуальную информацию и реальную помощь.

**Acceptance Criteria:**
1. Агент автоматически использует веб-поиск, когда нужна актуальная информация
2. При использовании инструмента — визуальный индикатор: «🔍 Ищу в интернете...», «📄 Читаю файл...»
3. Результаты инструментов интегрированы в ответ, а не показаны отдельно
4. Список доступных инструментов виден в настройках агента
5. Стоимость использования инструментов списывается вместе со стоимостью сообщения

## US-5: Загрузка файлов агенту

### US-5.1: Загрузка и анализ файлов

**Как** пользователь,  
**я хочу** загрузить файл и попросить агента его проанализировать,  
**чтобы** получить ответы по содержимому документа.

**Acceptance Criteria:**
1. Кнопка «📎» рядом с полем ввода — открывает файловый диалог
2. Поддерживаемые форматы: PDF, DOCX, TXT, PNG, JPG, CSV (с отображением в списке)
3. Ограничение: 1 файл до 25MB за раз
4. После загрузки файл отображается как превью в чате (имя, размер, иконка типа)
5. Агент автоматически анализирует файл и отвечает по его содержимому

### US-5.2: Управление загруженными файлами

**Как** пользователь,  
**я хочу** видеть все загруженные файлы и удалять ненужные,  
**чтобы** управлять своим пространством.

**Acceptance Criteria:**
1. Раздел «Файлы» в боковом меню — список всех загруженных файлов
2. Для каждого файла: имя, размер, дата загрузки, тип
3. Кнопка удаления с подтверждением: «Удалить файл? Агент больше не сможет к нему обращаться»
4. Отображение использованного / доступного места (квота: 500MB на MVP)

## US-6: Просмотр истории задач и баланса

### US-6.1: История расходов

**Как** пользователь,  
**я хочу** видеть детализацию расходов кредитов,  
**чтобы** понимать, на что тратятся мои деньги.

**Acceptance Criteria:**
1. Страница «Расходы» — таблица: дата, тип (чат/поиск/файл), модель, токены, стоимость
2. Фильтрация по дате (сегодня / неделя / месяц / произвольный период)
3. Сводка вверху: общий расход за период, средний расход в день, основная модель
4. Группировка по дням с sub-total
5. Экспорт в CSV

### US-6.2: История пополнений

**Как** пользователь,  
**я хочу** видеть историю платежей,  
**чтобы** контролировать свои траты.

**Acceptance Criteria:**
1. Таблица: дата, сумма (₽), кредиты, статус (успешно / ошибка / возврат)
2. Для каждого платежа — ID транзакции ЮKassa
3. Возможность повторить платёж (кнопка «Оплатить ещё раз» с той же суммой)

### US-6.3: Дашборд агента

**Как** пользователь,  
**я хочу** видеть общую статистику использования агента,  
**чтобы** понимать, насколько активно я его использую.

**Acceptance Criteria:**
1. Виджеты: баланс, сообщений за сегодня, файлов загружено, дней с регистрации
2. График расходов за последние 7 дней (bar chart)
3. Топ-3 типа использования (чат / поиск / файлы) — pie chart или процентная шкала
4. Обновляется в реальном времени при открытии
