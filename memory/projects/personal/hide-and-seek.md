# Hide & Seek — Игра для друга-программиста

**Статус:** ТЗ, не начато  
**Язык:** Rust  
**Цель:** Цифровая щекотка — программа бегает по файловой системе Windows, друг пытается поймать

---

## Механика

- Программа прыгает по папкам, меняет имя при каждом прыжке
- Мониторит открытые папки в Explorer (Windows COM API)
- Пользователь открыл папку где программа сидит:
  - **90%** — успевает сбежать (копирует себя, удаляет старую копию)
  - **10%** — не успела, остаётся на месте (можно поймать)

## Папки для прыжков

- Documents, Downloads, Pictures, Music
- AppData\Roaming, AppData\Local
- Случайные вложенные подпапки

## Первый запуск (от админа)

- UAC манифест — всегда запрашивает права администратора
- Добавляет себя в исключения Windows Defender (`Add-MpPreference`)
- Прописывает автозапуск в реестр (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`)

## Killswitch

Файл-флаг: `C:\Users\Public\.nomorerunning`

```cmd
echo. > C:\Users\Public\.nomorerunning
```

Программа при каждом прыжке проверяет этот путь.  
Если файл есть → удаляет все свои копии + автозапуск из реестра + исключение из Defender → самоуничтожается.

Друг знает что "есть способ остановить" — но не знает какой 😄

## Стек

- **Язык:** Rust
- **COM API:** для мониторинга Explorer окон
- **WinAPI:** для работы с файлами, реестром, атрибутами
- **Манифест:** `requireAdministrator` для UAC
- **PowerShell** через `std::process` для Defender exclusions

## Защита процесса

**1. Watchdog — два процесса**
- Основной процесс запускает дочерний-watchdog
- Следят друг за другом — если один убили, второй поднимает нового
- Убить оба одновременно через taskmgr крайне сложно

**2. Случайное имя процесса**
- При каждом прыжке exe переименовывается → имя процесса новое
- `taskkill /IM название.exe` не сработает — имя неизвестно

**3. Защита через WinAPI**
- `SetSecurityInfo` — запрещает другим процессам завершать себя
- Даже через taskmgr не убить, только SYSTEM может
- ⚠️ НЕ делаем — слишком агрессивно, Defender среагирует

## Нейросеть (адаптивный побег)

Tiny ONNX модель (~100-500KB, вшита в бинарь).

**Что делает:**
- Запоминает в какие папки друг заходил
- Учится избегать их — прыгает туда где ещё не искали
- Видит паттерн поиска (алфавитный порядок, глубина) → меняет стратегию
- Если запустил скрипты поиска → лезет глубже в подпапки
- Обучение с подкреплением: награда за успешный уход, штраф за поимку

**Имя процесса:**
Пул из ~20-30 реальных названий обычных программ (OneDrive.exe, Dropbox.exe, Discord.exe...).
При каждом прыжке — случайное из пула.

**Маскировка файла (при каждом прыжке):**
- Имя из пула реальных программ
- Дата создания → случайная ~1-2 года назад (`SetFileTime` WinAPI)
- Дата изменения → случайная ~1-6 месяцев назад
- Выглядит как давно установленная программа

## Защита от удаления папки

**Вариант 1 — превентивный:**
- Следит за папкой через `ReadDirectoryChangesW`
- Видит попытку удаления → прыгает ДО завершения
- Папка удаляется чисто, друг ничего не замечает

**Вариант 2 — воскрешение:**
- Программа не держит файл открытым (работает из памяти)
- Если удалили вместе с папкой → watchdog видит что файл исчез → создаёт новую копию в другом месте
- Друг думает победил → через секунду она снова живёт 👻

Оба варианта работают вместе как двойная страховка.

## Психологические уловки

**Ложный след:**
- Иногда оставляет пустой файл со своим именем в папке откуда убежала
- Друг находит, радуется — а там пусто 😄

**Провокация:**
- Раз в час создаёт `.txt` на рабочем столе: `"тепло... но не здесь"`, `"холодно 🥶"`, `"ищи лучше"`
- Удаляет через 30 секунд

## Техническая защита

**Шифрование в памяти:**
- Тело программы в RAM зашифровано
- Сложнее дампить и анализировать реверс-инжинирингом

**Anti-debug:**
- Следит за запуском x64dbg, Process Monitor, Wireshark, Process Hacker
- Если обнаружила → затаивается на час (перестаёт прыгать, минимальная активность)
- Друг думает что поймал — а она просто ждёт

## Геймификация

**Счётчик попыток:**
- Ведёт лог сколько раз её "почти поймали" (открыли папку где сидит)
- Показывает в финальной статистике после killswitch

**Уровни сложности:**
- Чем дольше идёт игра — тем умнее прячется
- День 1: прыгает в очевидные папки
- День 3+: лезет глубже в подпапки, реже прыгает, лучше маскируется

## Статистика и сбор данных

После killswitch программа показывает итоги:
```
Ты открыл 47 папок
Я прыгнула 23 раза  
Ближе всего ты был в C:\Users\...\Downloads
Нейросеть адаптировалась 8 раз
```

Затем спрашивает:
```
Отправить данные для улучшения модели? [Y/N]
```

При согласии — анонимная отправка паттернов поиска на сервер для дообучения.
