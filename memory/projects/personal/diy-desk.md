# DIY Подъёмный стол — Проект Дениса

**Создан:** 2026-03-15  
**Статус:** Планирование

---

## Концепция

Угловой Г-образный стол 150×150 см с электрической регулировкой высоты.  
3 телескопических колонки собственной конструкции, управление на ESP32 + FOC.

**Диапазон высот:** ~45 см (сидя на полу/лотос) → ~105 см (стоя, рост 172 см)  
**Ход колонки:** ~600 мм  
**Тишина:** BLDC + FOC + шариковый шпиндель + виброгасители  
**Расположение ног:** 3 штуки по Г-форме (лево-верх, право-верх, право-низ)

---

## Архитектура колонки

```
[BLDC мотор + планетарный редуктор]
           |
[Шариковый шпиндель SFU1605]
           |
  ┌────────────────┐
  │  Труба 80×80   │  ← наружная (неподвижная)
  │  ┌──────────┐  │
  │  │Труба60×60│  │  ← средняя
  │  │ ┌──────┐ │  │
  │  │ │Тр40×40│ │  │  ← внутренняя (к столу)
  │  │ └──────┘ │  │
  │  └──────────┘  │
  └────────────────┘
           |
    [Упорный подшипник]
           |
      [Основание]
```

Между секциями — вкладыши из PTFE (фторопласт 10мм).

## Программное обеспечение

**Стек:**
- ESP32 + Arduino / PlatformIO
- Библиотека SimpleFOC (simplefoc.com) — open source FOC для BLDC
- AS5048A через SPI для обратной связи по углу
- Синхронизация 3 колонок: каждые 10мс сравниваем позиции, притормаживаем опережающие
- PAJ7620 через I2C для жестов

**Фичи:**
- [ ] up/down кнопки

## План сборки

### Этап 1 — Механика
1. Нарезать трубы по размерам
2. Токарь: PTFE вкладыши под каждую секцию
3. Сварщик: нижние фланцы (к основанию) + верхние (под мотор)
4. Собрать секции, проверить ход (должно скользить без заеданий)
5. Поставить подшипник, вставить шпиндель SFU1605, накрутить гайку
6. Прикрутить мотор через фланец

**Проверка:** рукой двигать вверх-вниз — плавно, тихо, без люфта

### Этап 2 — Прототип одной колонки (самое важное)
1. Подключить мотор + AS5048A → SimpleFOC Shield → ESP32
2. Прошить базовый пример SimpleFOC
3. Настроить FOC (калибровка энкодера) — ~1-2 вечера
4. Написать логику: вращение мотора → движение шпинделя up/down
5. Убедиться что колонка работает стабильно

### Этап 3 — Три колонки + синхронизация
1. Собрать все три
2. Реализовать синхронизацию по AS5048A
3. Кнопки, пресеты, дисплей

### Этап 4 — Стол
1. Столешница + рама (знакомый мастер)
2. Прикрепить колонки, поставить виброгасители
3. Финальная калибровка

### Этап 5 — Фичи (потом)
- Жесты PAJ7620
- Дополнительные сенсоры

## Заметки

- **Критично:** начать с прототипа ОДНОЙ колонки перед сборкой трёх
- Шариковый шпиндель SFU1605 — стандарт CNC, легко найти на ali/purelogic
- SimpleFOC документация: docs.simplefoc.com
- Для синхронизации: AS5048A даёт абсолютный угол 14-bit → знаем точную позицию всегда
- Виброгасители важны — металл резонирует и усиливает любой шум
