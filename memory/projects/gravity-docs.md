# Gravity Group — Генерация документов

## Заявки (Заявка / Application)

### Как генерировать

**Скрипт:** `scripts/gravity_zavka_generator_v2.py`  
**Шаблон:** `/home/clawdbot/.openclaw/media/inbound/file_81---2141837f-9e85-45e3-9135-f0ffbf7ac458.docx`

**Подход:** ШАБЛОННАЯ ЗАМЕНА — открываем оригинал, заменяем данные, сохраняем.  
**НИКОГДА не создавать `Document()` с нуля!**

### Почему только шаблон

Оригинал содержит элементы, которые python-docx не умеет создавать:
1. **SDT (Structured Document Tags)** — названия компаний и ИНН через контент-контроли с dataBinding к свойствам документа
2. **numPr (автонумерация)** — "1.", "1.1.", "1.2." генерируются Word'ом, НЕ хранятся как текст
3. **Тема** — Calibri Light / Calibri (majorFont/minorFont)
4. **27 кастомных стилей** (не 164 дефолтных python-docx)
5. **Normal стиль** — Times New Roman 13pt, line_spacing=1.0
6. **App/Core properties** — Company и contentStatus привязаны к SDT через dataBinding

### SDT в шаблоне

| SDT alias | Что содержит | Привязка |
|-----------|-------------|----------|
| Наименование Заказчика | Полное название компании-заказчика | App Property: Company |
| ИНН Заказчика | ИНН заказчика | Core Property: contentStatus |

### ⚠️ Важно: НДС считается СВЕРХУ от оценки

НДС добавляется поверх суммы оценки (не включён "внутрь"):

```
оценка (база) = X руб  ← трудозатраты × ставка
НДС 5% = X × 0.05
итого в документе = X + НДС
```

❌ Неверно: `total * 5/105` (как будто НДС уже включён в сумму)
✅ Верно: `total * 0.05` (НДС на чистую сумму, результат — плюсуется)

**Пример для оценки 126 240 руб:**
- НДС 5% = 126 240 × 0.05 = **6 312 руб**
- Итого = 126 240 + 6 312 = **132 552 руб**
- В документе: "132 552 рублей, в т.ч. НДС 5% - 6 312 рублей"

```
              Техническое задание

```

### Границы таблиц (каждая уникальна!)

| Таблица | Границы |
|---------|---------|
| Стороны | insideH + insideV #5F497A, внешние = nil |
| Работы | ТОЛЬКО insideH #5F497A |
| Подписи | ТОЛЬКО insideV #5F497A, insideH = nil |
| ТЗ | Cell-level: чёрные 000000 внешние + серые CCCCCC внутренние |

### Форматирование

- Поля: 3.00cm слева, 1.50cm справа, 2.00cm сверху/снизу
- Шрифт: Calibri 12pt (через тему minorHAnsi)
- Интервал: space_before=120twips, space_after=120twips, line=288 (1.2)
- Hanging indent: firstLine=0 (в ячейках), left_indent=28.35pt + first_line_indent=-28.35pt (в параграфах)
- Деньги: пробел-разделитель ("166 057"), неразрывный пробел \xa0 в НДС
- Часы: запятая ("23,00")
- Даты: гиймеры ("«05» февраля 2026")
