### Сценарии использования
- **Основной:** In-Room синхрон — люди физически в конференц-зале, система переводит речь спикера и выдаёт на колонки/наушники в реальном времени
  - Схема: микрофон → STT → перевод → TTS → вывод
  - ⚠️ Нюанс: 4 языка одновременно → наушники логичнее колонок (иначе какофония), уточнить на встрече
- Видеоконференции (Zoom, Teams, Meet) — **ежедневно**, тариф Бизнес/Pro
- Одновременно два зала — **регулярно**

### Инфраструктура

- Интернет: стабильный

### Безопасность

- Внутренние политики безопасности

### Архитектурное решение
1. **Звонилка (WebRTC) = ядро системы.** Не отдельная фича, а основа для оркестрации аудиопотоков
2. Спринт-план: сначала веб-звонилка (аналог Telemost), потом на её базе — физические конференц-залы
3. Конференц-зал = постоянно запущенная комната, не нужно "звонить" — микрофоны и наушники привязаны к местам

### Конференц-зал — UX
- Каждое место: микрофон + наушники, идентифицированы в системе
- QR-код на месте → пользователь сканирует → выбирает язык (и опционально имя)
- Админ-панель управляет привязкой устройств ввода/вывода
- Один раз настроили → пользуются бесконечно

### Запись
- Видеозапись с демонстрацией экрана
- Несколько аудиодорожек — по одной на каждый язык
- Хранение в админке, скачивание

### Проблема с аппаратной частью заказчика
- У заказчика: **Gistron** (не Crestron!) беспроводная конгресс-система
  - Микрофонные пульты делегатов (беспроводные, до 250 шт, одновременно говорят до 3)
  - Центральный блок + аудиоматрица Eventa AP88
  - **Полностью аналоговая** — нет цифровых выходов по отдельным каналам
  - USB есть только на аудиоматрице (один общий поток)
  - Звук с отдельных микрофонов НЕ идентифицирован на выходе
- **Вывод:** с текущим оборудованием заказчика нельзя получить раздельные аудиопотоки по спикерам

### Варианты решения (обсуждались)
1. **Замена оборудования** — свои Wi-Fi микрофоны + наушники, программная маршрутизация (предпочтительный)
2. **Костыль** — две аналоговые системы (русский/хинди раздельно) → перевод общего потока. Некрасиво, но работает
3. **Raspberry Pi** на каждый микрофон — передатчик по Wi-Fi (идея Дениса, нужно изучить)
