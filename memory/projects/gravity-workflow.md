## Risk-First подход (обязательно!)

Перед любой оценкой:
1. Читаю ТЗ полностью
2. Составляю список вопросов по каждому неясному месту
3. Выявляю блокеры (интеграции, неопределённые сервисы, отсутствующие приложения)
4. Отправляю вопросы + риски в группу
5. Жду ответов → уточняю диапазон оценки

**Формат вопросов:**
```
❓ Вопросы к ТЗ:
1. [Критический] ...
2. [Важный] ...

⚠️ Риски:
1. [Высокий] ...
```
