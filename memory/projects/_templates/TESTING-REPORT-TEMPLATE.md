## 📝 Инструкция по использованию этого template:

**Для создания отчёта:**
1. Скопируй этот файл → `[project-name]-testing-report.md`
2. Замени все `[плейсхолдеры]` реальными данными
3. Добавь скриншоты (сохраняй в `/home/clawdbot/.openclaw/media/browser/`)
4. Конвертируй в docx: `pandoc report.md -o report.docx --resource-path=/path/to/images`
5. Отправь через `message.send()` с media

**Принципы хорошего отчёта:**
- ❌ Убирай технические детали (CLI, API, коды ошибок)
- ✅ Фокус на бизнес-влиянии и UX
- ✅ Визуальные примеры (скриншоты)
- ✅ Конкретные рекомендации с приоритетами
- ✅ Краткость (проектный руководитель читает за 5 минут)

**Структура:**
1. Executive Summary (что/почему/вывод)
2. Критичные находки (с визуалами)
3. Что работает (позитив тоже важен)
4. Рекомендации (конкретные + приоритет)
5. Скриншоты

**Язык:**
- Простой, понятный для не-технических людей
- Без жаргона (API, endpoint, CLI, snapshot)
- Фокус на пользовательском опыте
- Цифры где возможно (конверсия, влияние)
