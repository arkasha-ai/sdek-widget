# Logera — Помощник Проектного Руководителя

## Описание проекта

**Полное название:** Локальный инструмент для автоматической обработки и анализа звонков/документов

**Задача:** Автоматизировать рутину PM/руководителя проектов — транскрипция встреч, анализ документов, генерация отчётов, работа с базой знаний проекта.

**Статус:** Работающий pet-проект

**Репозиторий:** ai-notebook (приватный)

---

## Архитектура

**Backend:**
- FastAPI
- PostgreSQL (основная БД)
- ChromaDB (векторная БД для RAG)
- Docker

**Frontend:**
- Vue 3
- shadcn-vue

**AI компоненты:**
- Whisper + pyannote.audio/WhisperX (транскрипция + диаризация)
- Ollama (локальные LLM)
- LangChain (RAG pipeline)
- ChromaDB (векторный поиск)

---

## Функционал

### 1. Транскрипция + диаризация
- OpenAI Whisper — распознавание речи
- pyannote.audio/WhisperX — разделение по спикерам
- **Производительность:** Часовое видео обрабатывается за ~2 минуты

### 2. Работа с документами
- **Чтение:** PDF (pdfplumber), DOCX, OCR (Tesseract)
- **Генерация/редактирование:** Через ONLYOFFICE Document Server API
- **Текущее решение:** ONLYOFFICE Document Server API (real-time редактирование)

### 3. RAG + база знаний
- Ollama + ChromaDB + LangChain
- Контекстный поиск по всем документам и транскриптам
- AI-ассистент с контекстом всего проекта

### 4. Автоматизация
- Автоматическое саммари встреч
- Генерация протоколов
- Интеграция с чатом для редактирования документов через диалог

---

## Текущая проблема: ONLYOFFICE

**Ситуация:**
- ONLYOFFICE используется для работы с документами (Word/Excel)
- Может быть дорого или недоступно в будущем
- Нужна запасная альтернатива

**Требования к замене:**
- ✅ Полная поддержка возможностей Word/Excel
- ✅ Real-time редактирование (пользователь видит изменения live)
- ✅ Lossless конвертация (сохранение форматирования)
- ✅ On-premise (self-hosted)
- ✅ Бесплатно или дешевле ONLYOFFICE

---

## Рассмотренные альтернативы

### 1. Collabora Online (CODE - Community Edition) ⭐⭐
**Плюсы:**
- Open-source (MPL 2.0 license)
- Бесплатный
- Real-time collaboration
- WebSocket API (WOPI protocol)
- ~90-95% функционала ONLYOFFICE
- Можно форкать и улучшать

**Минусы:**
- Чуть хуже совместимость с MS Office (особенно сложные формулы Excel)
- Иногда теряется форматирование при конвертации
- Медленнее на больших документах
- Требует отдельный сервер

**Установка:**
```bash
docker run -t -d -p 9980:9980 \
  -e "domain=logera.example.com" \
  -e "username=admin" \
  -e "password=SECRET" \
  collabora/code
```

**Интеграция:** WOPI protocol (аналог ONLYOFFICE Document Server API)

### 2. Markdown редактор (текущий в Logera)
**Подходит для:**
- Простые документы (протоколы встреч, заметки, отчёты)
- Базовые таблицы
- Текст с разметкой
- Real-time легко реализуется

**НЕ подходит для:**
- Сложное форматирование
- Продвинутые таблицы (merged cells, conditional formatting)
- Формулы Excel
- Диаграммы, графики

**Hybrid подход:**
- 80% документов в Markdown (быстро, легко)
- 20% сложных → ONLYOFFICE/Collabora

### 3. Python-библиотеки (python-docx + openpyxl)
**Плюсы:**
- Лёгкие, без внешних зависимостей
- Полный контроль
- Уже используются в Office-Word-MCP-Server

**Минусы:**
- Меньше возможностей форматирования
- Нет real-time UI из коробки

**Для Excel:** openpyxl (чтение/запись) + pandas (анализ) покрывает 95% задач

### 4. LibreOffice headless + UNO API
**Плюсы:**
- Open-source, бесплатный
- Мощный API (Python bridge)

**Минусы:**
- Тяжеловесный
- Нужен headless режим для сервера
- Сложнее интеграция

## План действий

### Краткосрочный (сейчас)
1. Продолжить использовать ONLYOFFICE as-is
2. Markdown для 80% задач, ONLYOFFICE для 20% сложных

### Среднесрочный (3-6 месяцев)
1. **Поднять Collabora Online в test environment**
   - Docker контейнер
   - Интеграция через WOPI protocol
2. **Протестировать на реальных документах Logera**
   - Проверить конвертацию
   - Оценить потери форматирования
   - Сравнить производительность
3. **Если тесты успешны → migration plan**

### Долгосрочный (год+)
**Если Logera растёт и нужен уникальный функционал:**
- Форк Collabora Online
- Кастомизация под специфику проекта
- Улучшение конвертации
- Возможно продавать как "Logera Office"

**Альтернативный путь (умнее):**
- Collabora как backend (без изменений)
- Промежуточный слой для улучшений:
  - Добавление нужных API
  - Post-обработка (python-docx)
  - Интеграция с AI (Office-Word-MCP-Server)

## Ключевые метрики

- **Экономия времени:** Вместо ручного конспектирования встречи (30-60 мин) — автоматическая обработка + готовый протокол
- **Производительность:** Часовое видео → 2 минуты обработки (транскрипция + диаризация + саммари)
- **Конфиденциальность:** Полностью локальное решение (критично для корпоративного сектора)
