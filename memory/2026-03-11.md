## Marginalia — iOS crash fix

**Проблема:** Приложение Marginalia крашилось на iOS 26 при импорте EPUB после пары страниц.

**Диагностика:**
- Первоначально думал на sandbox/entitlements (ошибочно — добавил web-browser-engine entitlements, откатил)
- Затем думал на OOM от ONNX Runtime (частично верно, но не корень)
- **Корень:** `@huggingface/transformers@3.8.1` (v3) имеет подтверждённый баг утечки памяти на iOS/macOS — issue #1242

**Решение:**
- Даунгрейд на `@xenova/transformers@2.15.1` (v2 — без утечки)
- Заменены imports, `dtype:'q8'` → `quantized:true`
- Добавлен text-only search fallback (на случай если ONNX всё равно не загрузится)
- Пропуск cover generation на iOS (убирает двойной парс EPUB)

**Ветка:** `fix/ios-memory-crash` в `arkasha-ai/marginalia`
**Статус:** Запушено, ждём тестирования Денисом

**Коммиты:**
1. ~~Entitlements (откачен)~~
2. Skip ONNX on iOS (промежуточный)
3. Text-only search fallback
4. Downgrade to @xenova/transformers@2.15.1 (финальный фикс)
