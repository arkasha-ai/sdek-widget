### AI рендеры — сравнение моделей (по чертежу телескопической колонки)
Тестировали img2img по схеме колонки:
- **FLUX.1-dev** — первый тест, хорошо
- **FLUX.2-max** — лучше держит геометрию
- **Seedream-4** (bytedance) — хороший результат
- **Nano Banana Pro** (`google/nano-banana-pro`, Gemini 3 Pro) — **ПОБЕДИТЕЛЬ**, самый детализированный, шпиндель/гайка/подшипник видны чётко
- Модель поддерживает `image_input` (до 14 изображений), `resolution` = "1K"/"2K"/"4K"
- Rate limit на Replicate: burst=1 при балансе <$5 → нельзя параллельно, нужна пауза 12+ сек между запросами
- Проблема с сохранением: flux-pro/recraft возвращают bytes stream, нужно `b''.join(chunks)`, не urlretrieve

### Исправление скрипта рендера
Правильный способ сохранения для моделей возвращающих bytes:
```python
chunks = []
for item in output:
    chunks.append(item if isinstance(item, bytes) else str(item).encode())
data = b''.join(chunks)
if data.startswith(b'http'):
    url = data.decode().strip()
    with urllib.request.urlopen(url) as r:
        data = r.read()
img = Image.open(io.BytesIO(data)).convert('RGB')
img.save(out_path, 'JPEG', quality=92)
```
