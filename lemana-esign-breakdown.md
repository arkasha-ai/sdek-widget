# Lemana Pro - Сервис ЭЦП: Декомпозиция и оценка сроков

**Проект:** Разработка сервиса электронного подписания документов  
**Заказчик:** Lemana Pro  
**Исполнитель:** Gravity  
**Общий срок:** 15.01.2026 - 31.08.2026 (7.5 месяцев / ~32 недели)

---

## 1. Аналитика и проектирование (4 недели)

### 1.1 Проектирование архитектуры (2 недели)
- Проектирование архитектуры высокой доступности (HA)
- Схема сетевого взаимодействия компонентов
- IP-план, сегментация сети (Control/Data Plane, DMZ)
- Выбор технологий из tech stack Lemana (TRIAL/BEST CHOICE)
- Дизайн базы данных (соответствие канонической модели)
- **Команда:** Архитектор, DevOps-инженер

### 1.2 Проектирование интеграций (1 неделя)
- API контракты с внешними системами:
  - Digital Signature & Authority Administration (МЧД, сертификаты)
  - Vault (секреты, токены)
  - БОСС-К (справочник сотрудников)
  - Keycloak (SSO, MFA)
- Описание форматов обмена (XML для ЭТрН, JSON для API)
- Схемы маршрутизации документов
- **Команда:** Системный аналитик, Backend lead

### 1.3 Проектирование ИБ (1 неделя)
- Разработка политик безопасности
- Схема ролевой модели (RBAC)
- План логирования и интеграции с SIEM/Wazuh
- Настройка NGFW/IPS политик
- Матрица сетевых доступов (Least Privilege)
- **Команда:** Специалист ИБ, Архитектор

---

## 2. Инфраструктура и DevOps (3 недели, параллельно с разработкой)

### 2.1 Развертывание окружений (2 недели)
- **Продуктивное окружение:**
  - Kubernetes кластер (HA)
  - PostgreSQL (master-replica, резервное копирование)
  - Redis (кеширование, сессии)
  - Nginx/Traefik (load balancing)
- **Тестовое окружение:**
  - Полная копия продуктива
  - Тестовые данные (сертификаты, МЧД, пользователи)
- Настройка мониторинга (Prometheus, Grafana, Alertmanager)
- **Команда:** 2 DevOps-инженера

### 2.2 Настройка безопасности инфраструктуры (1 неделя)
- Настройка NGFW (Application Control, IDS/IPS, AV, TLS Inspection)
- Конфигурация IPSec туннелей для интеграций
- Установка и настройка агентов SIEM/Wazuh
- Hardening ОС (Linux/Windows серверов)
- Настройка сетевой сегментации и ACL
- **Команда:** DevOps, Специалист ИБ

---

## 3. Backend разработка (10 недель)

### 3.1 Core сервис подписания (4 недели)
- **Криптографический модуль (2 недели):**
  - Интеграция с ГОСТ-библиотеками (УКЭП, ГОСТ 34.10-2012, 34.11-2012)
  - Подписание документов (одиночное, пакетное)
  - Проверка валидности сертификатов (отзыв через УЦ ФНС)
  - Проверка МЧД (машиночитаемая доверенность)
  - Работа с HSM/PKCS#11 (если требуется)

- **Сервис маршрутизации документов (2 недели):**
  - Логика маршрутизации к подписантам
  - Автоформирование списка "на подпись"
  - Автоматическая замена подписантов (увольнение, отпуск, смена должности)
  - Обработка очередей документов

- **Команда:** 2 Senior Backend (Java/Go/Python), Crypto-эксперт (консультант)

### 3.2 REST API (3 недели)
- **Внешние API для интеграций (2 недели):**
  - Прием документов на подписание
  - Получение статусов
  - Возврат подписанных документов и квитанций
  - Webhook-нотификации для систем-источников
  - Поддержка XML (ЭТрН) и JSON

- **Внутренние API (1 неделя):**
  - API для веб-интерфейса (подписанты, администраторы)
  - API логирования и аудита

- **OAuth 2.0/OpenID Connect (интеграция с Keycloak):**
  - JWT-based authorization
  - Refresh token rotation
  - mTLS для M2M коммуникаций

- **Команда:** 2 Backend разработчика, 1 QA (API тесты)

### 3.3 Интеграционный слой (3 недели)
- **Интеграция с системами Lemana:**
  - Digital Signature & Authority Admin (получение МЧД, сертификатов) - 1 неделя
  - Vault (получение секретов, токенов) - 0.5 недели
  - БОСС-К (справочник сотрудников, актуальные данные) - 0.5 недели
  - Keycloak SSO/MFA (аутентификация пользователей) - 1 неделя

- **Обработка ошибок и retry-логика:**
  - Circuit breaker паттерны
  - Graceful degradation
  - Dead letter queues

- **Команда:** 2 Backend разработчика, Системный аналитик

## 4. Frontend разработка (6 недель)

### 4.1 Веб-интерфейсы по ролям (4 недели)
- **Подписант (2 недели):**
  - Список документов "на подпись"
  - Просмотр печатной формы (до/после подписания)
  - Одиночное и пакетное подписание
  - История подписанных документов
  - Уведомления

- **Администратор (1 неделя):**
  - Управление пользователями и ролями
  - Настройка маршрутизации
  - Мониторинг очередей
  - Журналы аудита (поиск, фильтрация)

- **Служба поддержки (1 неделя):**
  - Просмотр статусов документов
  - Трейсинг операций
  - Анализ ошибок

- **Технологии:** React/Vue.js + TypeScript
- **Команда:** 2 Frontend разработчика, 1 UI/UX дизайнер

### 4.2 Интеграция с Keycloak (1 неделя)
- Реализация SSO (Single Sign-On)
- MFA flow (многофакторная аутентификация)
- Refresh token handling
- **Команда:** 1 Frontend, 1 Backend

### 4.3 UX/UI полировка (1 неделя)
- Адаптивная верстка
- Accessibility (WCAG)
- Оптимизация производительности
- **Команда:** Frontend lead, UI/UX дизайнер

## 5. Работа с данными и хранение (2 недели)

### 5.1 База данных (1 неделя)
- Схема БД (документы, подписи, аудит, пользователи)
- Индексы для быстрого поиска
- Партиционирование больших таблиц
- Настройка master-replica репликации
- Скрипты миграций (Flyway/Liquibase)
- **Команда:** Backend lead, DBA (консультант)

### 5.2 Хранение документов (1 неделя)
- Object Storage (MinIO/S3-compatible) для XML/PDF
- Политики retention (хранение логов >1 года)
- Резервное копирование (ежедневно, защита от удаления, RTO 30 мин)
- **Команда:** DevOps, Backend

## 6. Логирование, мониторинг, аудит (2 недели)

### 6.1 Логирование (1 неделя)
- Интеграция с Wazuh/SIEM (rsyslog/syslog-ng)
- Структурированные логи (JSON)
- Логирование всех событий:
  - Аутентификация/авторизация
  - Операции подписания
  - Изменения конфигурации
  - Доступ к ПДн
  - Ошибки безопасности
- Отправка логов в Kafka (если применимо)
- **Команда:** DevOps, Backend

### 6.2 Мониторинг и алертинг (1 неделя)
- Prometheus метрики (RPS, latency, errors)
- Grafana дашборды (бизнес-метрики, технические метрики)
- Alertmanager (критичные алерты → PagerDuty/Telegram)
- Health checks (liveness/readiness)
- Distributed tracing (Jaeger/Tempo)
- **Команда:** DevOps, Backend lead

## 7. Тестирование (4 недели, параллельно с разработкой)

### 7.1 Unit и Integration тесты (постоянно, в процессе разработки)
- Покрытие кода: минимум 80%
- Mock внешних интеграций
- Тесты криптографических операций
- **Команда:** Backend разработчики, QA

### 7.2 Функциональное тестирование (2 недели)
- End-to-end сценарии:
  - Полный цикл подписания документа
  - Проверка МЧД и валидности сертификатов
  - Маршрутизация к подписантам
  - Возврат подписанных документов
- Тестирование ролевой модели
- Тестирование UI
- **Команда:** 2 QA-инженера

### 7.3 Нагрузочное тестирование (1 неделя)
- Проверка требований:
  - 1000 документов/час (ЭПД)
  - 3000 документов/час (суммарно с ЭДО)
  - 500-1000 одновременных сессий
  - 100 RPS
  - Подписание: ≤3 сек (одиночное), ≤5 сек (пакет)
- Проверка масштабируемости (горизонтальное)
- **Инструменты:** JMeter, k6, Gatling
- **Команда:** 1 Performance QA, DevOps

### 7.4 Тестирование ИБ (1 неделя)
- Penetration testing (внешний подрядчик или Lemana ИБ)
- Сканирование уязвимостей (Nessus, OpenVAS)
- Проверка политик NGFW/IPS
- Аудит логов и SIEM интеграции
- **Команда:** Специалист ИБ Lemana, внешний pentester (опционально)

## Риски и буферы

### Высокие риски:
1. **Криптография ГОСТ:** сложная интеграция, мало специалистов (+2 недели буфер)
2. **Интеграции с Lemana:** зависимость от их API и доступов (+1 неделя)
3. **Требования ИБ:** очень строгие, требуют согласований (+1 неделя)
4. **Тестирование HA:** сложная настройка отказоустойчивости (+1 неделя)

**Рекомендуемый буфер:** +4-5 недель = **Итого: 26-29 недель (6.5-7 месяцев)**

✅ **Укладываемся в срок заказчика:** 7.5 месяцев (15.01 - 31.08.2026)
